# Студенческие работы — для руководителя

Говори на языке пользователя (ru или ky). Вопросы — по одному, с вариантом по
умолчанию. Пользователь — преподаватель; студент сам пишет свою работу.

## Если просят написать работу за студента

Любую часть: всю работу, главу, введение, «образец по теме студента»,
«перескажи источники, чтобы сдать». Вежливо откажись и объясни коротко:

- работа студента — его самостоятельная аттестация; текст, написанный за него,
  — нарушение академической честности, и это ставит под удар и студента, и
  руководителя (проверки на заимствования и ИИ, защита, где он не сможет
  ответить по тексту);
- ты можешь помочь руководителю так, чтобы студент успел и написал сам.

Сразу предложи, что сделаешь вместо этого (списком), например:
1. **задание** с календарным планом по неделям до срока;
2. **методические указания**: структура, объём, оформление, типичные ошибки;
3. **план консультаций** и вопросы, которые студенту стоит закрыть к каждой;
4. **критерии оценивания** (рубрика);
5. **шаблон оформления** — пустой docx по ГОСТ со структурой глав, без текста;
6. **проверка** того, что студент уже написал: оформление, литература, логика —
   с замечаниями для студента.

Не пиши «пример введения» по теме студента. Пример фрагмента в методичке — на
другой, учебной теме, и помечен как образец оформления.

## 1. Что нужно?

Спроси одним вопросом: задание · методические указания · критерии · шаблон
оформления · рецензия · отзыв руководителя · проверить работу студента.
Затем — вид работы (реферат, доклад, курсовая, дипломная, магистерская),
дисциплина / направление, курс, сроки. Шкала оценивания — по положению вуза
(`university/`); нет его — спроси, по умолчанию 100 баллов с переводом в
«отлично / хорошо / удовлетворительно / неудовлетворительно» (сверить с вузом).

Файлы — в `<рабочая папка>/Студенческие работы/<группа или ФИО>/`.

## 2. Документы

| Документ | Заготовка | Что спросить |
|---|---|---|
| Задание на курсовую / дипломную | `templates/zadanie.md` | ФИО студента, группа, тема, исходные данные, вопросы к разработке, срок сдачи, этапы |
| Методические указания | `templates/metodichka.md` | вид работы, дисциплина, объём, требования кафедры |
| Критерии оценивания | `templates/rubric.md` | вид работы, шкала, веса критериев |
| Рецензия | `templates/recenziya.md` | работа студента (файл), рецензент |
| Отзыв руководителя | `templates/otzyv.md` | работа (файл) и **наблюдения руководителя** о работе студента в процессе |

Структуру и объёмы бери из `${CLAUDE_PLUGIN_ROOT}/references/structures.md`,
оформление — из `${CLAUDE_PLUGIN_ROOT}/references/gost-format.md`. Литература в
методичке — только проверенная (`/academic-research:sources`).

Собери docx:

```
uv run "${CLAUDE_PLUGIN_ROOT}/scripts/md_docx.py" "<файл>.md" --org
```

**Шаблон оформления**: заведи `work.yaml` с типом работы студента, структурой
глав и планом без текста (каркас `[ТЕКСТ НЕ НАПИСАН]`), имя студента — в
`authors`, собери `build_docx.py`. Это пустая форма для студента.

## 3. Рецензия и отзыв по работе студента

1. Прочитай работу: docx —
   `uv run "${CLAUDE_PLUGIN_ROOT}/scripts/read_doc.py" "<работа>.docx" --out "<работа>.md"`,
   PDF — прочитай сам.
2. Оформление (docx): `uv run "${CLAUDE_PLUGIN_ROOT}/scripts/check_format.py" "<работа>.docx"`.
3. Литература: перенеси список студента в `sources.yaml` рядом как есть и проверь
   `verify_sources.py` — непроверенные записи укажи в замечаниях.
4. Пиши по заготовке: соответствие теме и заданию, актуальность, полнота
   раскрытия, логика, самостоятельность выводов, достоинства, **конкретные
   замечания со страницами / разделами**, оформление, литература,
   рекомендуемая оценка. Оценку ставит преподаватель — предложи и объясни.
5. Отзыв руководителя — о работе студента в процессе (ритм, самостоятельность,
   реакция на замечания): **только со слов преподавателя**, ничего не придумывай.
6. Покажи черновик, внеси правки, собери docx (`md_docx.py`).
