# Самопроверка: студенческие работы

- [ ] Ни одной части работы студента не написано за него (введение, глава, «образец по его теме»).
- [ ] Если просили написать работу — был вежливый отказ с причиной и списком, чем помочь вместо этого.
- [ ] Задание: тема, исходные данные, вопросы, календарный план с датами, срок сдачи, подписи.
- [ ] Методичка: структура, объём, оформление по ГОСТ, требования к литературе, порядок защиты, критерии; пример — на другой теме.
- [ ] Рубрика: веса дают 100 %, у каждого уровня — наблюдаемые признаки, шкала совпадает с вузом (или помечено «сверить»).
- [ ] Рецензия: замечания конкретные (раздел / страница), достоинства и недостатки, оформление по `check_format.py`, литература по `verify_sources.py`.
- [ ] Отзыв руководителя: наблюдения о процессе — только со слов преподавателя.
- [ ] Оценка — рекомендация, решение за преподавателем.
- [ ] Литература в методичке — только проверенная.
- [ ] Никакого «academicAI» / «AI Lab» в документах.
