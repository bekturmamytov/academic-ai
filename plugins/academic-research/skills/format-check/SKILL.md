# Проверка оформления по ГОСТ

Говори на языке пользователя (ru или ky), простыми словами. Вопросы — по одному.

Нормы — `${CLAUDE_PLUGIN_ROOT}/references/gost-format.md`. Если в рабочей
папке есть положение вуза (`university/`) или требования журнала — они
главнее: прочитай и скажи, где они расходятся с ГОСТ.

## 1. Файл

Спроси путь к docx (по умолчанию — последний файл в `out/` текущей работы).
PDF проверить так нельзя — попроси docx. Чужая работа (студента) — можно:
это проверка, а не написание.

## 2. Проверка

```
uv run "${CLAUDE_PLUGIN_ROOT}/scripts/check_format.py" "<файл>.docx"
```

Код 1 — есть критичные замечания, 0 — нет. Покажи итог списком: сначала
**критично**, потом **внимание**; у каждого — что не так и где. Скажи, что
из этого скрипт исправит сам (отмечено «исправимо --fix»).

## 3. Исправление

Спроси: «Исправить поля, шрифт, кегль, интервал, отступы, выравнивание и номера
страниц автоматически? Исходный файл не изменится — будет копия
«…_исправлено.docx».» По согласию:

```
uv run "${CLAUDE_PLUGIN_ROOT}/scripts/check_format.py" "<файл>.docx" --fix
```

Скрипт сам перепроверит копию. Чего он не трогает — объясни, как сделать
в Word (по шагам, одним списком):

- **заголовки** — выделить → Главная → Стили → «Заголовок 1 / 2»; без точки в конце;
- **оглавление** — Ссылки → Оглавление → Автособираемое; обновить — F9;
- **подписи** — Ссылки → Вставить название: «Таблица 1 – …» над таблицей,
  «Рисунок 1 – …» под рисунком;
- **список литературы** — переоформить через `/academic-research:sources`
  (проверка + ГОСТ Р 7.0.100);
- **метки** `[НУЖНЫ ВАШИ ДАННЫЕ]`, `[НУЖЕН ИСТОЧНИК]`, `[НЕ ПРОВЕРЕНО]` — их
  закрывает только автор своими данными и проверенными источниками; сами мы их
  не заполняем.

Документ собран нашими скриптами (`out/*.docx`) — правь не docx, а `work.yaml`
и `chapters/*.md`, затем пересобери `build_docx.py`: иначе правки потеряются.

## 4. Самопроверка

Пройди `references/checklist.md`, покажи найденное списком. Затем путь к
проверенному (или исправленному) файлу и одна следующая команда.
