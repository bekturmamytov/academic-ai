# Самопроверка: оформление

- [ ] Проверен именно docx, путь показан пользователю.
- [ ] Замечания показаны списком: сначала критичные, потом остальные.
- [ ] Исправление делалось только с согласия и только в копию; исходный файл цел.
- [ ] После `--fix` показан результат перепроверки.
- [ ] Для неисправимого автоматически — шаги в Word или нужная команда.
- [ ] Метки и непроверенные ссылки не «исправлялись» — их закрывает автор.
- [ ] Расхождения положения вуза / журнала с ГОСТ названы, если положение есть.
