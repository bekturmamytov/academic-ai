# Требования журнала — чек-лист перед отправкой

Заполняется по «Требованиям к авторам» журнала. Нет требований — ориентир по
типовым требованиям журналов КР и ГОСТ.

| Пункт | Типовое | Что проверить |
|---|---|---|
| Профиль журнала | тема статьи в рубриках журнала | рубрика выбрана |
| Перечень НАК КР | нужен для защиты | автор проверил на сайте НАК КР |
| Индексация | РИНЦ, Scopus, Web of Science — по задаче автора | указано в `journal` |
| Объём | 5–15 с. | считать без списка литературы? — как в требованиях |
| Оформление | Times 14, 1,5 или журнал свой (часто 12 / 1,0) | кегль, интервал, поля |
| УДК | обязателен в журналах КР | указан автором / библиотекой |
| Заглавие ru / ky / en | часто на трёх языках | переводы есть |
| Авторы | ФИО, степень, должность, организация, город, e-mail, ORCID | всё со слов авторов |
| Аннотация | 150–250 слов, ru / ky / en | цель, методы, результаты, вывод; без ссылок |
| Ключевые слова | 5–7 на каждом языке | |
| Структура | IMRaD или своя | разделы как в журнале |
| Рисунки, таблицы | подписи, ссылки в тексте, качество ≥ 300 dpi | |
| Ссылки | ГОСТ Р 7.0.100 / APA / IEEE, число источников, доля свежих | только `verified: true` |
| Самоцитирование | часто ограничено | доля своих работ |
| Оригинальность | порог антиплагиата журнала | автор проверил |
| Политика об ИИ | раскрытие, запрет ИИ в соавторах, ИИ-изображения | `journal.ai_policy` и `ai_disclosure` согласованы |
| Конфликт интересов, финансирование, благодарности | по требованиям | только со слов автора |
| Сопроводительные | направление организации, рецензия, лицензионный договор | автор знает список |
