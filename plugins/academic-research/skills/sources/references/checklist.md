# Самопроверка: литература

- [ ] Ни одна запись не написана по памяти: всё из реестра, со страницы пользователя или из его файла.
- [ ] `verified` выставлен только `verify_sources.py`; в этой сессии скрипт запускался после последней правки.
- [ ] Записи из списка пользователя перенесены как есть, без «исправлений по памяти».
- [ ] Каждая непроверенная запись показана пользователю с причиной и шагом, что сделать.
- [ ] Подсказанная замена (другой DOI) внесена только с согласия и перепроверена.
- [ ] Для КиберЛенинки / eLibrary есть `url` или `file`; законы — `type: law`, `note`.
- [ ] Ключи `key` уникальны, латиницей.
- [ ] В оформленном списке — только `verified: true`; стиль = `citation_style` работы.
- [ ] Не было связи — пользователь знает, что проверка не прошла.
