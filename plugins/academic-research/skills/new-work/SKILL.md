# Новая научная работа

Говори на языке пользователя (ru или ky), простыми словами — он преподаватель,
не программист. Вопросы **по одному**, у каждого — вариант по умолчанию.

Прочитай перед работой:
- `${CLAUDE_PLUGIN_ROOT}/references/work-schema.md` — поля паспорта;
- `${CLAUDE_PLUGIN_ROOT}/references/structures.md` — структура по типам;
- `${CLAUDE_PLUGIN_ROOT}/templates/work.example.yaml` — образец.

## 1. Рабочая папка и профиль

Найди `profile.yaml` в текущей папке или выше. Нет — предложи `/academic:setup`
или спроси ФИО, должность, степень, вуз, кафедру, город и запиши их в
`profile.yaml` рабочей папки. Автор работы (`authors[0]`) берётся оттуда.

## 2. Тип работы

Спроси, что пишем, коротким списком: статья · тезисы · доклад · реферат ·
магистерская · кандидатская (+ автореферат) · курсовая · дипломная.

**Курсовая, дипломная, реферат** — уточни: «Это ваша собственная работа или
работа студента?» Если студента — объясни, что готовую работу за студента мы не
пишем, и предложи `/academic-research:student-work` (задание, методичка,
критерии, рецензия, шаблон оформления). Свою (например, реферат к кандидатскому
экзамену или вторая магистратура) — продолжаем.

## 3. Вопросы по паспорту

Спрашивай только нужное для типа, по одному:

| Вопрос | Для кого | По умолчанию |
|---|---|---|
| Тема (рабочая) | все | — |
| Язык документа | все | язык из `profile.yaml` |
| Соавторы по порядку (ФИО, степень, организация, e-mail, ORCID) | статья, тезисы, доклад | только вы |
| Научный руководитель / консультант | магистерская, кандидатская, реферат аспиранта | — |
| Шифр и название специальности, отрасль науки | магистерская, кандидатская | **не подставляй по памяти** — спроси; шифр из действующей номенклатуры НАК КР |
| Направление / дисциплина | реферат, курсовая, дипломная | — |
| Журнал: название, ссылка или файл «Требования к авторам» | статья | «пока не выбран» |
| Конференция: название, даты, место, секция | тезисы, доклад | — |
| Стиль ссылок | все | ГОСТ; для статьи — как требует журнал |
| Есть ли у вас свои данные (таблицы, замеры, анкеты, результаты) и где они | все, кроме реферата | «пока нет» |
| Требует ли журнал / вуз / НАК раскрывать использование ИИ | статья, диссертации | «не знаю — проверим позже» |

Не знает ответа — запиши пустым и иди дальше; не выдумывай.

## 4. Структура

Предложи структуру по `structures.md` для типа: заголовки глав и план разделов
под тему. Это **план**, не текст. Покажи списком, дай поправить, затем запиши в
`structure` (статус `plan`). Для кандидатской сразу добавь блок `avtoreferat`.

## 5. Создай папку

```
<рабочая папка>/Научная работа/<короткое название темы>/
  work.yaml      ← из образца, заполненный ответами
  sources.yaml   ← «sources: []»
  chapters/      ← файл на каждый пункт structure: план как «## раздел» + строка [ТЕКСТ НЕ НАПИСАН]
  data/  figures/  out/
```

Свои данные пользователя скопируй (или укажи путь) в `data/` и опиши в `data[]`.
Проверь паспорт сборкой каркаса:

```
uv run "${CLAUDE_PLUGIN_ROOT}/scripts/build_docx.py" "<папка работы>/work.yaml"
```

Ошибки скрипта (по-русски) — исправь в `work.yaml` и пересобери.

## 6. Самопроверка

Пройди `references/checklist.md`, покажи найденное списком. Затем — путь к
папке и одна следующая команда: `/academic-research:sources` (подобрать и
проверить литературу), потом `/academic-research:paper` или
`/academic-research:thesis`.
