# Структура работ по типам

Общие нормы КР и межгосударственные ГОСТ. Образцов вуза пока нет — если у
пользователя есть положение вуза (`university/`), **оно главнее** этого файла.
Пометка «сверить» — норма может отличаться в вузе или в действующем положении.

## Реферат

ВВЕДЕНИЕ (актуальность, цель, задачи) → 2–3 главы обзора → ЗАКЛЮЧЕНИЕ → СПИСОК
ИСПОЛЬЗОВАННОЙ ЛИТЕРАТУРЫ → приложения. Реферат — обзор чужих работ, поэтому
каждая мысль опирается на источник. Реферат к кандидатскому экзамену
(история и философия науки) пишет сам аспирант — режим соавтора.

## Доклад / тезисы

- **Тезисы**: УДК, заглавие, авторы, организация, e-mail, (аннотация и ключевые
  слова — если требует сборник), текст 1–3 с.: проблема → что сделано → главный
  результат → вывод; 3–7 источников.
- **Доклад на конференцию**: то же, полнее; к нему часто — презентация
  (`academic-core`).

## Научная статья (IMRaD)

| Раздел | Что внутри |
|---|---|
| УДК, заглавие, авторы, аффилиации, ORCID, e-mail | по требованиям журнала |
| Аннотация ru / ky / en | 150–250 слов: цель, методы, результаты, вывод — пишется **последней** |
| Ключевые слова ru / ky / en | 5–7 |
| Введение | проблема, что известно (со ссылками), пробел, цель |
| Материалы и методы | данные автора, методика — так, чтобы можно было повторить |
| Результаты | только по данным автора: таблицы, рисунки |
| Обсуждение | сравнение с другими работами, ограничения |
| Заключение | ответ на цель |
| Благодарности, финансирование, конфликт интересов, заявление об ИИ | если требует журнал |
| Список литературы | по стилю журнала |

Свой шаблон журнала (`journal.structure: journal`) — берётся из требований
к авторам, разделы называются как в журнале.

## Курсовая работа

ВВЕДЕНИЕ (актуальность, цель, задачи, объект, предмет, методы) → глава 1
теоретическая → глава 2 практическая / аналитическая → ЗАКЛЮЧЕНИЕ → СПИСОК
ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ → ПРИЛОЖЕНИЯ. Перед введением — задание на курсовую
(если требует кафедра).

## Дипломная (выпускная квалификационная) работа

Титул → задание → (аннотация) → СОДЕРЖАНИЕ → ВВЕДЕНИЕ (актуальность, цель,
задачи, объект, предмет, методы, практическая значимость, структура) → 2–3 главы
(теория → анализ объекта → проект / эксперимент) → ЗАКЛЮЧЕНИЕ → СПИСОК → ПРИЛОЖЕНИЯ.
К защите — отзыв руководителя и рецензия (их делает преподаватель через
`student-work`). Название на титуле в вузах КР встречается и «ДИПЛОМНАЯ РАБОТА»,
и «ВЫПУСКНАЯ КВАЛИФИКАЦИОННАЯ РАБОТА» — `doc_label` в `work.yaml`; сверить с вузом.

## Магистерская диссертация

Как дипломная, но во введении — **научная новизна**, **положения, выносимые на
защиту**, **апробация** (конференции, публикации), практическая значимость.
Главы — «ГЛАВА 1.», разделы «1.1.».

## Кандидатская диссертация

Структура и элементы введения — в `references/nak-kr.md`. Порядок:
титул → ОГЛАВЛЕНИЕ → (перечень сокращений) → ВВЕДЕНИЕ → главы (обычно 3–4, в
конце каждой — выводы по главе) → ЗАКЛЮЧЕНИЕ (выводы, практические рекомендации)
→ СПИСОК ИСПОЛЬЗОВАННОЙ ЛИТЕРАТУРЫ → ПРИЛОЖЕНИЯ (акты внедрения и т. п.).

## Автореферат

Титул «На правах рукописи» → оборот (где выполнена, руководитель, оппоненты,
ведущая организация, защита, библиотека, дата рассылки, учёный секретарь) →
ОБЩАЯ ХАРАКТЕРИСТИКА РАБОТЫ (те же пункты, что во введении диссертации) →
ОСНОВНОЕ СОДЕРЖАНИЕ РАБОТЫ (по главам) → ВЫВОДЫ (+ практические рекомендации)
→ СПИСОК ОПУБЛИКОВАННЫХ РАБОТ ПО ТЕМЕ ДИССЕРТАЦИИ → РЕЗЮМЕ на кыргызском,
русском и английском (ФИО, тема, ключевые слова, объект, цель, методы,
результаты, область применения) — **сверить с актуальным положением НАК КР**.
Формат печати автореферата (часто брошюра A5, кегль меньше) — сверить; `build_docx`
собирает A4 по ГОСТ, переформатировать под типографию — отдельно.
