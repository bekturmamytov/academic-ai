# ElevenLabs: ключ и голос

Озвучка идёт через **ваш** аккаунт ElevenLabs (elevenlabs.io): символы списываются с вашего
тарифа, мы ключ не храним и никуда, кроме ElevenLabs, не отправляем.

## Ключ

1. elevenlabs.io → профиль → **API Keys** → Create. Права: Text to Speech.
2. Создайте файл `.env` в папке `.academic` в домашней папке
   (macOS: `~/.academic/.env`, Windows: `%USERPROFILE%\.academic\.env`) со строкой:
   ```
   ELEVENLABS_API_KEY=ваш_ключ
   ```
   Можно и переменной окружения `ELEVENLABS_API_KEY`.
3. Проверка: `render.py --check` пишет «Ключ ElevenLabs: найден».

## Голос

- Модель — `eleven_v3` (ru, en; ky — проверьте на 2–3 слайдах).
- Голос по умолчанию — из библиотеки ElevenLabs. Свой: Voices → голос → «ID» →
  `--voice <ID>` или строка `ELEVENLABS_VOICE_ID=<ID>` в `.env`.
- Клон своего голоса — только в своём аккаунте и со своего согласия (Voices → Add voice).

## Цена

`narrate.py … --mode elevenlabs --estimate` показывает число символов заранее.
Лекция на 15 минут — порядка 12–15 тысяч символов. Неизменённые слайды при пересборке
повторно не оплачиваются (кэш в `out/video/.build/`).

## Ошибки

- 401 — ключ не подошёл: проверьте строку в `.env`, без кавычек и пробелов.
- 402 / 429 — закончились символы тарифа или слишком частые запросы.
- 404 — голос с таким ID не найден в вашем аккаунте.
