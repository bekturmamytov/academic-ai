# Самопроверка видео-лекции

Проверь и покажи список «замечание — что сделать» (или «замечаний нет»).

1. **Файлы.** На каждую часть есть `NN-partK.mp4` и `NN-partK.srt`.
2. **Формат.** `ffprobe -v error -show_entries stream=width,height,codec_name -of csv=p=0 <mp4>` →
   `h264,1920,1080`; в режимах с голосом есть дорожка `aac`.
3. **Длина частей.** Каждая ≤ 15 мин (короче 8 — только если короток сам раздел).
4. **Кадры.** 2–3 кадра на часть: текст не обрезан, не наезжает на титры, читается;
   заставка — курс, тема, ФИО; концовка — на языке лекции.
5. **Титры.** Язык титров = язык лекции; первые реплики `.srt` совпадают с началом заметок.
6. **Заметки.** Слайды без заметок перечислены пользователю (на них нет голоса и титров).
7. **Голос** (elevenlabs / recording): послушай начало 1–2 слайдов — голос на своём слайде,
   не обрывается; ky + ElevenLabs — пользователь подтвердил, что звучит приемлемо.
8. **Чистота.** В кадре нет «academicAI», «AI Lab» и чужих логотипов — видео принадлежит преподавателю.
9. **Ключ.** Ключ ElevenLabs нигде не показан: ни в ответе, ни в файлах рядом с видео.
