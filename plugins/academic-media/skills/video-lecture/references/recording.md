# Своя запись голоса

Подойдёт диктофон телефона, гарнитура или микрофон ноутбука. Тихая комната важнее микрофона.

## Способ 1 — файл на слайд (надёжнее)

1. Откройте заметки докладчика и читайте по слайду.
2. Каждый слайд — отдельный файл, в имени номер слайда: `01.m4a`, `02.m4a`, … (подойдут
   mp3, m4a, wav, ogg; `слайд 3.m4a` тоже распознается).
3. Все файлы — в одну папку, например `<папка курса>/out/video/запись-05/`.
4. Пропустили слайд — он пойдёт без голоса, на него хватит времени прочитать титры.

```
uv run "${CLAUDE_PLUGIN_ROOT}/scripts/render.py" "<слайды>" --mode recording --recording "<папка>"
```

## Способ 2 — одна запись

1. Читайте лекцию подряд, **перед каждым новым слайдом — пауза 2–3 секунды** молча.
   Внутри слайда паузы короче секунды.
2. Число длинных пауз должно быть не меньше числа переходов (слайдов − 1).
   Скрипт режет по самым длинным паузам; если пауз не хватит, он скажет об этом.

```
uv run "${CLAUDE_PLUGIN_ROOT}/scripts/render.py" "<слайды>" --mode recording --recording "<файл>"
```

После сборки посмотрите 2–3 перехода: голос должен начинаться на своём слайде.
Если съехало — проще записать файл на слайд.

## Титры

Титры берутся из заметок. Если читали своими словами — титры разойдутся с голосом:
поправьте заметки под сказанное или соберите без титров — флаг `--no-captions`.
