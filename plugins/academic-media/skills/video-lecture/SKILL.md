# Видео-лекция из слайдов (beta)

Пользователь — преподаватель, не программист. Говори на его языке (ru или ky),
простыми словами, **вопросы по одному**, у каждого — вариант по умолчанию.
Пути и команды — для его ОС; скрипты запускай так, как ниже (работает на macOS и Windows).

## 1. Найди слайды

Источник — `out/slides/NN.yaml` в папке курса (его пишет `/academic-core:slides`, там есть
заметки докладчика — это текст озвучки). Если есть только `.pptx` — тоже подходит:
текст и заметки достанет скрипт. Если слайдов нет — предложи сначала
`/academic-core:slides` и остановись.

Схема `slides.yaml` и что в ней важно для видео — `references/slides-format.md`.
Пустые `notes` = на слайде нет голоса и титров; предупреди и предложи дописать заметки.

## 2. Проверь окружение

```
uv run "${CLAUDE_PLUGIN_ROOT}/scripts/render.py" --check
```

Нужны Node.js 20+ и ffmpeg. Если скрипт пишет, чего не хватает, — скажи это одной фразой
и предложи `/academic:setup`; дальше не иди. Первый запуск ставит движок видео в
`~/.academic/remotion` (нужен интернет, 1–3 минуты) — предупреди.
Строка «Ключ ElevenLabs: найден / не найден» нужна для шага 3. Сам ключ никогда не печатай.

## 3. Вопросы (по одному)

1. **Голос.** Предложи три варианта:
   1) голос ElevenLabs — по ключу вашего аккаунта ElevenLabs, символы списываются с вашего тарифа;
   2) своя запись — вы читаете лекцию сами, мы раскладываем запись по слайдам;
   3) без голоса — только титры (бесплатно, быстрее всего).
   По умолчанию: 1, если ключ найден; иначе 3. Ключа нет, а хочется 1 — шаг 4.
2. **Язык** озвучки и титров: ru / ky / en. По умолчанию — `lang` из слайдов или
   `language` из `profile.yaml`. Для **ky + ElevenLabs** скажи честно: качество кыргызского
   у `eleven_v3` ещё не проверено — сначала озвучим 2–3 слайда и послушаем (шаг 4),
   если плохо — своя запись или титры.
3. **Нарезка.** По умолчанию — по разделам, ролики до 15 минут (обычно 8–15). Или один ролик (`--single`).

## 4. Голос ElevenLabs

Озвучка идёт **только по ключу самого преподавателя** — его аккаунт ElevenLabs, его тариф.
Общего ключа нет. Ключ лежит в `~/.academic/.env` (Windows: `%USERPROFILE%\.academic\.env`)
строкой `ELEVENLABS_API_KEY=…` или в переменной окружения `ELEVENLABS_API_KEY`.
Где взять ключ и как выбрать голос — `references/elevenlabs.md`.

- Ключа нет — открой файл для ключа и объясни: вставить ключ после `=`, сохранить, написать «готово»:
  ```
  uv run "${CLAUDE_PLUGIN_ROOT}/scripts/key.py" --open
  ```
- Ключ есть — проверь его до озвучки (принят ли, тариф, остаток символов):
  ```
  uv run "${CLAUDE_PLUGIN_ROOT}/scripts/key.py" --check
  ```
  Ошибку (ключ не принят, не прошла оплата, кончились символы) перескажи и предложи
  своя запись или только титры — работа не стоит из-за ключа.
- Не проси присылать ключ в чат и не читай `.env`. Если пользователь сам прислал ключ —
  предложи `key.py --open` и попроси вставить туда; в ответе ключ не повторяй.
- Перед озвучкой покажи цену в символах и спроси «да»:
  ```
  uv run "${CLAUDE_PLUGIN_ROOT}/scripts/narrate.py" "<слайды>" --mode elevenlabs --estimate
  ```
- Голос по умолчанию — из библиотеки ElevenLabs; свой (в т. ч. клон своего голоса — только
  в своём аккаунте и со своего согласия) — `--voice <ID>` или `ELEVENLABS_VOICE_ID` в `.env`.
- Сначала озвучь без видео и дай послушать 1–2 файла из `<out>/.build/<NN>/audio/`:
  ```
  uv run "${CLAUDE_PLUGIN_ROOT}/scripts/narrate.py" "<слайды>" --mode elevenlabs --lang ru --out "<папка курса>/out/video/.build/<NN>"
  ```
  Готовые фразы кэшируются: сборка видео их не оплачивает второй раз, пока текст не изменён.

## 5. Своя запись

Прочитай `references/recording.md` и объясни пользователю один из двух способов:
файл на каждый слайд (`01.m4a`, `02.m4a` …) в одной папке или одна запись с паузой
2–3 секунды перед каждым новым слайдом. Запись с телефона подходит.
Титры в этом режиме берутся из заметок: если читали своими словами, они разойдутся
с голосом — предложи поправить заметки под сказанное или собрать без титров (`--no-captions`).

## 6. Собери видео

```
uv run "${CLAUDE_PLUGIN_ROOT}/scripts/render.py" "<слайды>" --mode none|elevenlabs|recording --lang ru [--recording "<файл или папка>"] [--voice ID] [--single] [--no-captions]
```

- Результат: `<папка курса>/out/video/NN-partK.mp4` и `NN-partK.srt` рядом
  (`--out` — другая папка). Служебное — в `out/video/.build/`.
- Время: примерно минута сборки на минуту видео. Скажи об этом заранее; одну часть
  можно пересобрать `--only-part K`.
- Ошибки скрипт пишет по-русски — перескажи простыми словами и предложи, что сделать.

## 7. Самопроверка

Пройди `references/checklist.md` и покажи найденное списком (или «замечаний нет»).
Обязательно посмотри кадры: вытащи 2–3 кадра из каждой части и открой их
(`ffmpeg -ss <сек> -i <mp4> -frames:v 1 <png>`), проверь, что текст не обрезан и читается.

## 8. Итог

Список файлов (mp4 и srt) с длительностью частей и одна следующая команда, например:
«загрузите `NN-part1.mp4` и `NN-part1.srt` в Moodle; следующая лекция — `/academic-media:video-lecture`».
