# Лекция по теме курса

Лекция пишется **из паспорта курса** (`course.yaml`: тема, часы, РО, ЦУР, литература)
и **материалов преподавателя** — они главный источник. Ты — соавтор: структура,
изложение, примеры, активные методы. Факты не выдумываешь.

Говори на языке преподавателя (ru или ky), просто. Вопросы — **по одному**, с
вариантом по умолчанию в скобках.

## 1. Курс и тема

1. Найди `course.yaml` (в текущей папке, в папке курса или спроси путь). Нет — предложи
   `/academic-core:new-course`.
2. Покажи темы списком (неделя, тема, часы лекций, есть ли уже `lectures/NN-*.md`).
   Спроси: «Какую тему пишем? (первая без лекции)» или «все темы — курс лекций?».
3. Курс лекций — пиши по одной теме, после каждой показывай итог и спрашивай,
   продолжать ли. Не пиши 15 лекций молча.

## 2. Материалы преподавателя

Спроси: «Есть ваши материалы по теме — старый конспект, презентация, статья, методичка?
Пришлите файлы — лекция будет опираться на них».

- docx / pptx / pdf → `uv run "${CLAUDE_PLUGIN_ROOT}/scripts/extract_text.py" "<файл>"`
  (скан без текста — прочитай через Read).
- Материалы есть — бери из них определения, примеры, порядок изложения, терминологию.
  Расходишься с ними — скажи, где и почему.
- Материалов нет — пиши по общепринятому содержанию дисциплины, но всё, что требует
  ссылки (цифры, даты, статистика, цитаты, «по данным…»), помечай `[нужен источник]`.

## 3. Напиши `lectures/NN-<slug>.md`

Структура, объём и разметка — прочитай `references/lecture-structure.md`.
Образец — `templates/lecture.example.md` (в папке этого skill).

Коротко:

- Содержание темы — поле `content` темы в паспорте: все его пункты должны быть в лекции
  (в плане и изложении). Расширять можно, выбрасывать — только с согласия преподавателя.
- Шапка YAML: `week`, `title`, `outcomes` (РО темы из паспорта), `sdg`.
- Разделы: `## План`, `## Цели и результаты обучения`, `## Ключевые понятия`
  (пункты «**Термин** — определение»: из них собирается глоссарий УМКД),
  `## Изложение` (подразделы `###` по пунктам плана), `## Связь с устойчивым развитием`
  (если ЦУР уместна — без натяжек), `## Активные методы`, `## Вопросы для самопроверки`,
  `## Литература`.
- Объём — по часам лекций темы: ~1500–2000 слов на академический час.
- Имя файла: номер недели двумя цифрами + короткий slug латиницей: `03-relyacionnaya-model.md`.

### Честность

- **Литература — только из паспорта** (`literature` в `course.yaml`) и из файлов
  преподавателя. Новый источник не придумывай; если нужен — предложи найти и добавить
  в паспорт через `/academic-core:new-course` с проверкой. Скрипт помечает источники не
  из паспорта `[НЕ ПРОВЕРЕНО]`.
- Цифры, проценты, даты, имена, цитаты без источника — не пиши с ложной точностью
  («73,4 % вузов…»). Либо качественная формулировка без цифры («многие организации»),
  либо пометка `[нужен источник]`. Ссылки на безымянные авторитеты («по оценкам
  экспертов», «исследования показывают») — тоже `[нужен источник]`.
- Примеры из Кыргызстана — только общеизвестные или от преподавателя.

## 4. Собери docx

Одна лекция:

```
uv run "${CLAUDE_PLUGIN_ROOT}/scripts/build_lecture.py" "<папка курса>/lectures/03-<slug>.md"
```

Курс лекций (все `lectures/*.md` → один файл с титулом и оглавлением):

```
uv run "${CLAUDE_PLUGIN_ROOT}/scripts/build_lecture.py" "<папка курса>/course.yaml"
```

Результат — `out/lectures/NN.docx` или `out/lectures/lectures.docx`. Оглавление Word
обновит при открытии (или правой кнопкой → «Обновить поле»).

Скрипт печатает предупреждения: нет раздела, источник не из паспорта, пометки
`[нужен источник]`. Каждое — исправь в `.md` или явно перечисли преподавателю.

## 5. Самопроверка и итог

Пройди `references/checklist.md`, покажи результат списком (✓ / ! что осталось).
Обязательно перечисли все пометки `[нужен источник]` / `[НЕ ПРОВЕРЕНО]` — их снимает
только преподаватель.

Затем — путь к файлу и одна следующая команда: «сделайте презентацию к лекции:
`/academic-core:slides`».
