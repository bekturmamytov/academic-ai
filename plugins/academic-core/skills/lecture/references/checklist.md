# Чек-лист лекции

Проверь `.md` и вывод `build_lecture.py`. Каждый пункт — ✓ или ! с пояснением.

**Соответствие паспорту**
1. Тема и номер недели совпадают с `topics` в `course.yaml`.
2. РО в лекции — коды и формулировки из паспорта, ничего не добавлено.
3. ЦУР — из `sdg` паспорта; связь с темой реальная, не притянутая.

**Структура**
4. Есть все разделы: план, цели и РО, ключевые понятия, изложение, активные методы,
   вопросы для самопроверки, литература (скрипт не выдал «нет раздела»).
5. Пункты плана = подразделы изложения, в том же порядке.
6. Ключевые понятия оформлены «**Термин** — определение» (для глоссария УМКД).
7. Объём соответствует часам лекции (≈1500–2000 слов на академический час).

**Активные методы**
8. Есть вопросы для перевёрнутого класса, кейс с вопросами, мини-задание с формой результата.
9. Вопросы для самопроверки — 5–8, разных уровней Блума.

**Честность**
10. Литература — только из паспорта или файлов преподавателя; скрипт не пометил
    источники `[НЕ ПРОВЕРЕНО]` (или преподаватель знает о каждом).
11. Нет цифр, дат, цитат и ссылок на «исследования» без источника; где нужно —
    `[нужен источник]`, и все такие места перечислены преподавателю.
12. Вымышленные кейсы помечены как условные; реальные организации — только с данными преподавателя.

**Файл**
13. `out/lectures/NN.docx` (или `lectures.docx`) создан; в нём нет «academicAI» / «AI Lab».
