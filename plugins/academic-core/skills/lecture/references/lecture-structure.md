# Структура лекции

Файл `lectures/NN-<slug>.md` — Markdown с YAML-шапкой. Скрипт `build_lecture.py`
понимает: заголовки `#`–`####`, абзацы, **жирный**, *курсив*, `код`, списки `-` и
`1.` (вложенность — два пробела), таблицы `| … |`, цитаты `>`, картинки
`![подпись](путь)`, разрыв страницы `\pagebreak`. Пометки `[нужен источник]`,
`[нужны ваши данные]`, `[НЕ ПРОВЕРЕНО]` подсвечиваются жёлтым.

```markdown
---
week: 3
title: "Реляционная модель. Ключи и связи"
outcomes: [РО1, РО3]
sdg: [4, 9]
---

# Лекция 3. Реляционная модель. Ключи и связи
```

## Разделы по порядку

| Раздел | Что внутри | Норма |
|---|---|---|
| `# Лекция N. Тема` | заголовок лекции = тема недели из паспорта | один на файл |
| `## План` | 3–5 пунктов = подразделы изложения | нумерованный список |
| `## Цели и результаты обучения` | 1–2 цели лекции; РО темы из паспорта с кодами (РО1…), глагол Блума | РО не придумывать, брать из `outcomes` |
| `## Ключевые понятия` | 4–10 терминов: `- **Термин** — определение.` | из них собирается глоссарий УМКД |
| `## Изложение` | `### 1. …` по пунктам плана; объяснение → пример → вывод | 1500–2000 слов на акад. час |
| `## Связь с устойчивым развитием` | 1 абзац: какая ЦУР (номер и название) и как тема с ней связана | только если связь реальная; ЦУР — из паспорта `sdg` |
| `## Активные методы` | см. ниже | минимум 3 элемента |
| `## Вопросы для самопроверки` | 5–8 вопросов разных уровней Блума | от «перечислите» до «предложите» |
| `## Литература` | 2–5 источников **из паспорта курса** | ГОСТ Р 7.0.100-2018 |

## Активные методы

- **Перевёрнутый класс** — 2–3 вопроса, на которые студент ищет ответ *до* лекции
  (по литературе или короткому видео преподавателя).
- **Кейс** — ситуация из практики (лучше местная, Кыргызстан / Центральная Азия), 3–5
  предложений + 2 вопроса для обсуждения в группах. Ситуация вымышлена — так и скажи
  («условный пример»); реальные организации и цифры — только от преподавателя.
- **Мини-задание** на 5–10 минут в аудитории: что сделать, форма результата.
- По желанию: «думай — работай в паре — делись», мини-опрос, PBL-задача на неделю.

## Изложение

- Абзацы короткие, термин при первом упоминании — жирным.
- Сначала идея простыми словами, потом строгое определение, потом пример.
- Сравнения — таблицей; процессы — нумерованным списком шагов.
- Картинки и схемы — `![подпись](img/файл.png)` только если файл есть у преподавателя;
  иначе текстом опиши, какую схему нарисовать на доске, — в презентации это станет
  схемой.

## Язык

Лекция на языке курса (`language` в паспорте). Для кыргызского — термины как в
учебниках на кыргызском; если устоявшегося термина нет, в скобках дай русский.
