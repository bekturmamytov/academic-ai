# Формат slides.yaml

```yaml
lecture: lectures/03-relyacionnaya-model.md   # откуда взято (для справки)
week: 3                                         # номер → out/slides/03.pptx
title: "Реляционная модель. Ключи и связи"      # титульный слайд
subtitle: "Лекция 3"                            # необязательно
language: ru                                    # необязательно, по умолчанию из паспорта
title_notes: "Что сказать на титульном слайде"  # необязательно
slides:
  - type: section            # слайд-раздел: большой номер и название
    title: "Отношения и атрибуты"
    notes: "…"
  - type: content            # тезисы, можно со схемой / картинкой справа
    title: "Что такое отношение"
    bullets:
      - "**Отношение** — таблица со строками и столбцами"   # **…** — жирный
      - text: "Атрибут — столбец"
        sub: ["имя", "тип", "домен"]                         # подпункты
    diagram: {kind: steps, items: ["Сущность", "Отношение", "Таблица"]}
    notes: "Полный текст для преподавателя…"
  - type: table
    title: "Термины модели и SQL"
    table:
      header: ["Модель", "SQL"]
      rows: [["Отношение", "Таблица"], ["Атрибут", "Столбец"]]
    notes: "…"
questions:                   # заключительный слайд; нет — «Спасибо за внимание»
  - "Чем первичный ключ отличается от внешнего?"
closing_notes: "…"
```

## Типы слайдов

| `type` | Поля | Когда |
|---|---|---|
| `section` | `title`, `subtitle`, `notes` | начало пункта плана |
| `content` | `title`, `bullets` и/или одно из `diagram`, `image`, `placeholder`, `notes` | основной слайд |
| `table` | `title`, `table.header`, `table.rows`, `notes` | сравнение, классификация |

`type` можно не писать: есть `table` — таблица, иначе — `content`.

## Визуальные блоки

- `diagram.kind: steps` — шаги со стрелками (до 6). Рядом с тезисами — столбиком,
  на весь слайд — в ряд. Элемент — строка или `{title, text}`.
- `diagram.kind: cards` — карточки 2×N: понятия, виды, принципы.
- `image: {path: img/файл.png, description: "…"}` — картинка преподавателя (путь от
  slides.yaml); файла нет — пунктирная рамка «Изображение: описание».
- `placeholder: "Схема: путь запроса от клиента к диску"` — место под схему, которую
  преподаватель нарисует или вставит сам.

Есть и тезисы, и визуальный блок — тезисы слева (~половина), блок справа.

## Оформление (делает скрипт)

16:9, белый фон, Arial; акцент — `color` из `university/brand.yaml`; логотип `logo` —
справа сверху на каждом слайде и на титуле; внизу — название курса и номер слайда.
Кегль подбирается под объём (28 → 16 pt); не влезает и в 16 — предупреждение.
