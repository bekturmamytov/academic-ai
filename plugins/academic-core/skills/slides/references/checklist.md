# Чек-лист презентации

Каждый пункт — ✓ или ! с пояснением.

**Содержание**
1. Слайды идут по плану лекции; на каждый пункт плана — слайд-раздел.
2. Все факты и цифры есть в лекции; пометок `[нужен источник]` на слайдах нет.
3. Есть слайды с активными методами (кейс, мини-задание, вопросы) и, если тема связана, — ЦУР.
4. Заключительный слайд — 3–5 вопросов для самопроверки.

**Нормы оформления**
5. Заголовки ≤ 8 слов; на слайде ≤ 6 пунктов (скрипт не предупредил).
6. Заметки докладчика есть на каждом слайде, кроме служебных, и это полный текст, а не тезисы.
7. Картинки — только файлы преподавателя; остальное — места с описанием.

**Вид (по рендеру, если был)**
8. Текст не выходит за рамки, ничего не перекрывается, схемы читаются.
9. Цвет и логотип — из `university/brand.yaml`; на титуле курс и ФИО преподавателя.
10. Нет «academicAI» / «AI Lab» на слайдах и в заметках.
