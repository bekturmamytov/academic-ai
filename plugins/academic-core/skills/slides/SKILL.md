# Презентация к лекции

Источник — готовая лекция `lectures/NN-*.md` (skill `/academic-core:lecture`). Лекции
нет — предложи сначала написать её; можно и по материалам преподавателя (pptx/docx).

Говори на языке преподавателя (ru или ky), вопросы — по одному.

## 1. Что берём

1. Найди `course.yaml` и лекцию по теме. Спроси, какую тему, если неясно
   («последняя лекция — 03, по ней?»).
2. Если у преподавателя есть старая презентация — извлеки текст
   (`uv run "${CLAUDE_PLUGIN_ROOT}/scripts/extract_text.py" "<файл.pptx>"`) и учти её
   порядок и картинки.
3. Картинки — только файлы преподавателя (положи в `slides/img/`). Своих не ищи и не
   генерируй; где картинка нужна, ставь место для неё с описанием.

## 2. Напиши `slides/NN-slides.yaml`

Формат и примеры типов слайдов — `references/slides-format.md`; образец —
`templates/slides.example.yaml`.

Правила:

- 12–20 слайдов на 2 часа лекции; раздел (`type: section`) на каждый пункт плана.
- Заголовок ≤ 8 слов. На слайде ≤ 6 пунктов, пункт ≤ 12 слов — тезис, не абзац.
- **Заметки докладчика (`notes`) — полный текст**, что говорит преподаватель на этом
  слайде, разговорным языком, из лекции. Слайд без заметок — ошибка.
- Процесс, этапы, цикл → `diagram: {kind: steps}`; 2–4 понятия рядом → `kind: cards`;
  сравнение → `type: table` (до 6 строк).
- ЦУР — отдельный слайд, если она есть в лекции; активные методы — слайды с заданием
  (кейс, мини-задание) и вопросы перевёрнутого класса.
- `questions` — 3–5 вопросов для самопроверки из лекции; они идут на заключительный слайд.
- Цифры и факты — только те, что есть в лекции; пометки `[нужен источник]` на слайды
  не выноси, сначала их снимает преподаватель.

## 3. Собери pptx

```
uv run "${CLAUDE_PLUGIN_ROOT}/scripts/build_slides.py" "<папка курса>/slides/03-slides.yaml"
```

Результат — `out/slides/03.pptx`: 16:9, белый фон, акцентный цвет `color` и логотип
`logo` из `university/brand.yaml` (по умолчанию `#1F4E79`, без логотипа), шрифт Arial.
Первый слайд — курс, тема, преподаватель из `profile.yaml`; последний — вопросы.
Рядом — `out/slides/03.yaml`: та же презентация в простой схеме для видео-лекции
(`academic-media`); руками его не правь — пересобери из `slides.yaml`.

Скрипт предупреждает: длинный заголовок, больше 6 пунктов, текст не помещается,
нет заметок. Исправь `slides.yaml` и пересобери.

## 4. Посмотри на слайды

Если есть LibreOffice (`soffice`), отрендери и **посмотри** картинки сам:

```
soffice --headless --convert-to pdf --outdir "<папка курса>/out/slides" "<папка курса>/out/slides/03.pptx"
pdftoppm -r 50 -png "<папка курса>/out/slides/03.pdf" "<папка курса>/out/slides/preview"
```

Проверь: текст не вылезает за рамки, схемы читаются, нет пустых слайдов. Нет
`soffice` — опирайся на предупреждения скрипта и скажи, что визуально не проверено.

## 5. Самопроверка и итог

Пройди `references/checklist.md`, покажи результат списком.

Скажи преподавателю: файл можно открыть в PowerPoint и доработать вручную или
попросить Claude отполировать его нативным skill `pptx` (анимации, свои картинки,
перекладка). Затем — путь к файлу и одна следующая команда: «задания к теме:
`/academic-core:srs`» или «видео-лекция по слайдам: `/academic-media:…`», если
плагин `academic-media` установлен.
