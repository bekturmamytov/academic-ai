# Отчёты преподавателя

Три вида — один скрипт:

| `type` | Документ | Данные |
|---|---|---|
| `individual_plan` | Индивидуальный план работы преподавателя на учебный год | нагрузка и планируемые работы — от преподавателя |
| `plan_report` | Отчёт о выполнении индивидуального плана | тот же план + факт часов и отметки о выполнении |
| `course_report` | Отчёт по дисциплине: распределение оценок, средний балл, успеваемость, качество | **только** ведомость преподавателя (xlsx / csv) |

**Цифры не придумываем никогда.** Нет нагрузки, нет ведомости — спроси или оставь
поле пустым; скрипт без файла оценок отчёт по дисциплине не соберёт.

Говори на языке преподавателя (ru или ky), вопросы — по одному.

## 1. Какой отчёт

Спроси: «Какой документ нужен: индивидуальный план, отчёт о его выполнении или отчёт
по дисциплине? (индивидуальный план)». Если у вуза своя форма (docx) — попроси файл,
извлеки текст (`uv run "${CLAUDE_PLUGIN_ROOT}/scripts/extract_text.py" "<файл>"`) и
сверь разделы; несовпадения назови.

Папка: `<рабочая папка>/Отчёты/<учебный год>/` (план и отчёт о плане) или папка курса
(отчёт по дисциплине).

## 2. Данные → `report.yaml`

Поля — `references/yaml-fields.md`, образцы — `templates/plan.example.yaml`,
`templates/course_report.example.yaml`.

**План / отчёт о плане** — собирай по разделам, по одному:

1. Учебная работа: дисциплины, группы, семестр, часы по видам (из паспортов курсов —
   `course.yaml` — если они есть, иначе спроси). Для отчёта — `fact`.
2. Учебно-методическая: УМКД, пособия, силлабусы, новые курсы — с месяцем срока.
   Подскажи то, что уже сделано в рабочей папке (`out/umkd.docx`, `out/manual.pdf`).
3. Научная: статьи, конференции, гранты, руководство студентами — **только то, что
   назовёт преподаватель**; не придумывай журналы и темы.
4. Воспитательная: кураторство, мероприятия.
5. Организационная / общественная (необязательно).
6. Для отчёта: `result` у каждого пункта — «выполнено», «перенесено на …», «не выполнено:
   причина»; `conclusions` — 2–4 предложения по итогам.

**Отчёт по дисциплине:**

1. Попроси ведомость (xlsx или csv): ФИО и итоговый балл 0–100. Столбец с баллом
   скрипт ищет по словам «итог», «балл», «total», «жыйынтык»; иначе — `score_column`.
2. `course:` — путь к `course.yaml` (дисциплина, семестр, кредиты).
3. Сначала собери без выводов — скрипт напечатает итоги (средний балл, успеваемость,
   качество). Потом **предложи выводы на основе этих чисел** (что получилось, что
   улучшить: темы, методы, СРС) и запиши в `conclusions` только после согласия.

## 3. Сборка

```
uv run "${CLAUDE_PLUGIN_ROOT}/scripts/build_report.py" "<папка>/report.yaml"
```

Результат — `out/report_<type>.docx` (в папке курса, если рядом `course.yaml`).
Шкала — курса (`grading_scale`) или вуза (`university/settings.yaml` → `grading.scale`),
иначе КР: 87–100 A «отлично», 80–86 B и 74–79 C «хорошо», 68–73 D и 61–67 E
«удовлетворительно», 0–60 F. Успеваемость — доля с баллом от нижней положительной
оценки (по КР ≥ 61), качество — от нижней «хорошо» (по КР ≥ 74).

## 4. Самопроверка и итог

Пройди `references/checklist.md`, покажи результат списком. Перечисли предупреждения
скрипта (пустые разделы, нет отметок, студенты без балла).

Затем — путь к файлу и одна следующая команда (например, «отчёт о выполнении в конце
года — та же команда с `type: plan_report`»).
