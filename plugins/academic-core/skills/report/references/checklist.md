# Чек-лист отчёта

Каждый пункт — ✓ или ! с пояснением.

**Данные**
1. Все цифры — от преподавателя: нагрузка, факт часов, баллы из ведомости. Ничего не дописано «для полноты».
2. Научные работы, мероприятия, публикации — только названные преподавателем.
3. Отчёт по дисциплине: файл ведомости указан, столбец балла найден верно, студенты
   без балла названы.

**Состав**
4. План: все четыре раздела (учебная, учебно-методическая, научная, воспитательная);
   пустые — преподаватель знает.
5. Отчёт о плане: у каждого пункта есть отметка о выполнении; факт часов указан.
6. Нагрузка: итог часов посчитан; совпадает с нагрузкой кафедры (спроси, если есть).

**Выводы**
7. Выводы опираются только на посчитанные числа и слова преподавателя; согласованы с ним.

**Оформление**
8. Шапка: вуз, кафедра, учебный год, ФИО, должность; подписи внизу.
9. Нет «academicAI» / «AI Lab» в документе.
