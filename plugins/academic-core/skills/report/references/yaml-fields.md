# Поля report.yaml

## Индивидуальный план / отчёт о выполнении

```yaml
type: individual_plan        # individual_plan | plan_report
academic_year: "2026-2027"
rate: "1,0"                  # ставка (необязательно)
teacher: {}                  # необязательно: name, position, degree — иначе из profile.yaml
teaching:                    # 1. Учебная работа
  - discipline: "Базы данных"
    group: "ПИ-1-24"
    semester: 3
    lectures: 30
    practicals: 15
    labs: 30
    other: 10                # консультации, экзамены, практика, руководство ВКР
    fact: 85                 # только для plan_report: выполнено часов
methodical:                  # 2. Учебно-методическая
  - name: "Разработка УМКД по дисциплине «Базы данных»"
    deadline: "декабрь 2026"
    result: ""               # для plan_report: «выполнено», «перенесено на …»
research: []                 # 3. Научная
educational: []              # 4. Воспитательная
other: []                    # 5. Организационная и общественная (необязательно)
conclusions: |               # для plan_report: итоги
  …
```

Пункт раздела — словарь (`name`, `deadline`, `result`) или просто строка.

Документ: вуз, кафедра, «УТВЕРЖДАЮ» (для плана), заголовок, учебный год, ФИО,
должность, степень, ставка; таблица нагрузки (план; в отчёте — и факт); таблицы
разделов «№ — наименование — срок — отметка о выполнении»; подписи преподавателя и
заведующего кафедрой.

## Отчёт по дисциплине

```yaml
type: course_report
course: ../course.yaml       # паспорт курса (название, семестр, кредиты)
group: "ПИ-1-24"
grades: grades.xlsx          # ведомость преподавателя: xlsx (первый лист) или csv (; , или табуляция)
score_column: "Итог"         # необязательно: имя столбца с итоговым баллом
conclusions: |               # выводы — после согласования с преподавателем
  …
```

Скрипт считает: число студентов, аттестованных (есть балл), распределение по шкале
КР (A–F, количество и %), средний балл, успеваемость (≥ 61), качество знаний (≥ 74).
Пустой балл — «не аттестован», предупреждение. Балл вне 0–100 — ошибка.
