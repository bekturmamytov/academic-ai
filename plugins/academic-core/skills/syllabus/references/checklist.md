# Чек-лист силлабуса

Проверь по тексту готового docx. Каждый пункт — ✓ или ! с пояснением.

**Состав**
1. Титульный лист: министерство, вуз, факультет, кафедра, «УТВЕРЖДАЮ», название
   «Силлабус по дисциплине …», направление, курс/семестр, кредиты, город, год.
2. Все 13 разделов из `structure.md` на месте и пронумерованы по порядку (кроме скрытых
   вузом в `syllabus.hide_sections`; свои разделы вуза — перед подписями).
3. Нет пустых «—» там, где преподаватель дал данные (ФИО, контакты, описание).

**Часы и кредиты**
4. В таблице часов: всего = кредиты × 30; Л + П + Лаб + СРСП + СРС = всего.
5. Строка «Итого» тематического плана совпадает с таблицей часов по каждому виду.
6. Тем по неделям столько же, сколько недель (обычно 15); рубежные контроли в своих неделях.

**Результаты обучения**
7. 3–7 РО, каждый начинается с измеримого глагола Блума; уровень в таблице ему соответствует.
8. У каждого РО есть недели, где он формируется; у каждой темы есть РО.

**Оценивание**
9. Сумма максимальных баллов = 100; есть текущий, рубежный и итоговый контроль.
10. Шкала оценок покрывает 0–100 без пропусков.

**Содержание**
11. ЦУР названы с номерами и названиями; методы обучения указаны.
12. У каждой темы с часами СРС есть задание, форма и срок сдачи.
13. Политика курса: посещаемость, сроки, академическая честность, правило про ИИ.

**Литература и честность**
14. Основная литература есть; записи по ГОСТ Р 7.0.100-2018.
15. Всё непроверенное помечено `[НЕ ПРОВЕРЕНО]` (или убрано в чистовике `--final`);
    скажи преподавателю, сколько таких записей.
16. Нет выдуманных источников, номеров протоколов, дат утверждения.
17. В документе нет упоминаний academicAI, AI Lab, Claude.

**Язык**

    (скрипт перечисляет поля без перевода); кыргызский текст — рекомендовать проверку носителем.
