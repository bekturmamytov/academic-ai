# Силлабус

Силлабус собирается **из паспорта курса** скриптом — не пиши docx вручную.
Структура документа и нормы — `references/structure.md`; чек-лист — `references/checklist.md`.
Говори с преподавателем на его языке (ru / ky), вопросы — по одному.

## 1. Паспорт курса

1. Найди `course.yaml`: в текущей папке курса, или спроси, какой курс (покажи список
   папок с `course.yaml` в рабочей папке).
2. Нет паспорта — скажи «сначала заполним паспорт курса» и пройди skill
   `academic-core:new-course` (вопросы или перенос из старого силлабуса), затем вернись сюда.

## 2. Проверка и пробелы

```
uv run "${CLAUDE_PLUGIN_ROOT}/scripts/validate_course.py" "<папка курса>/course.yaml"
```

- **Ошибки** (часы ≠ кредиты × 30, баллы ≠ 100, РО «знает…») — исправь в
  `course.yaml`. Арифметику правь сам и скажи, что поменял; содержание — спроси.
- **Предупреждения**, важные для силлабуса, — спроси по одному, с готовым вариантом:
  ФИО и контакты (лучше в `profile.yaml`), описание, цели, ЦУР, методы, политика
  курса (в т. ч. правило про ИИ), задания СРС, основная литература.
  Преподаватель может ответить «пропусти» — тогда в документе будет «—».
- Литература без `verified: true` попадёт в документ с пометкой `[НЕ ПРОВЕРЕНО]`.
  Предложи проверить её (Crossref / OpenAlex / КиберЛенинка) — найденное отметь
  `verified: true`, не найденное оставь как есть. Не добавляй источники по памяти.

## 3. Язык

Язык документа — `language` паспорта. Нужен другой (`ky`, `en`) или оба:

- добавь в `course.yaml` переводы полей с суффиксом: `title_ky`, `text_ky`,
  `srs_task_ky`, `description_ky`, `goals_ky`, `attendance_ky`… (список полей без
  перевода скрипт печатает после сборки);
- переводи сам, термины — как в положениях Минобрнауки КР; кыргызский текст
  предложи проверить носителю языка;
- метки разделов, ЦУР, уровни Блума, шкалу оценок скрипт переводит сам.

## 4. Сборка

```
uv run "${CLAUDE_PLUGIN_ROOT}/scripts/build_syllabus.py" "<папка курса>/course.yaml" --lang ru
```

- `--lang ru|ky|en` — язык; для двух языков запусти дважды.
- `--final` — чистовик: непроверенная литература не попадает в документ.
- Файл: `<папка курса>/out/syllabus_<lang>.docx`.
- Ошибка «закройте файл в Word» — попроси закрыть документ и запусти снова.

Правила вуза — `university/settings.yaml` рабочей папки (справочник —
`${CLAUDE_PLUGIN_ROOT}/references/university-settings.md`): название, министерство и
город на титуле, «УТВЕРЖДАЮ» / «СОГЛАСОВАНО», поля и шрифт, шкала оценок, скрытые
разделы (`syllabus.hide_sections`), свои разделы (`syllabus.extra_sections`), политика
по умолчанию (`syllabus.policies`; текст курса главнее). Факультет и кафедра — из
`profile.yaml`. Вуз дал свой образец силлабуса, а настроек нет — предложи
`/academic-core:university`, не правь docx руками.

## 5. Самопроверка

1. Прочитай готовый docx (skill `docx` или `extract_text.py`):

   ```
   uv run "${CLAUDE_PLUGIN_ROOT}/scripts/extract_text.py" "<папка курса>/out/syllabus_ru.docx"
   ```

2. Пройди `references/checklist.md` по тексту документа. Покажи итог списком:
   ✓ — в порядке, ! — что нужно преподавателю (подписи, протокол, непроверенная
   литература, переводы на проверку).
3. Нашёл ошибку в данных — исправь `course.yaml` и пересобери, не правь docx руками.

## 6. Итог

Путь к файлу, 1–3 пункта «что заполнить от руки» (подписи, номер протокола) и одна
следующая команда: «рабочая программа и тематический план в Excel: `/academic-core:rup`».
В документ не добавляй никаких упоминаний academicAI, AI Lab или Claude.
