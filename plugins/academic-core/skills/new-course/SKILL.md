# Новый курс: паспорт `course.yaml`

Паспорт — единый источник: из него собираются силлабус, РУП, тесты, лекции, УМКД.
Схема — `${CLAUDE_PLUGIN_ROOT}/references/course-schema.md` (прочитай перед работой),
образец — `${CLAUDE_PLUGIN_ROOT}/templates/course.example.yaml`.

Говори на языке преподавателя (ru или ky), просто, без терминов YAML. Вопросы —
**по одному**, с вариантом по умолчанию в скобках: «Сколько кредитов? (5)».
Не выдумывай данные: чего нет — спроси или оставь пустым и скажи об этом.

## 1. Где курс

1. Найди рабочую папку: `profile.yaml` в текущей папке или выше. Нет — предложи
   сначала `/academic:setup` (там создаётся профиль); можно продолжить и без него.
2. Папка курса: `<рабочая папка>/<код> <название>/` (например `ИС-201 Базы данных/`).
   Если `course.yaml` там уже есть — спроси: дополнить или начать заново.

## 2. Выбери путь

Спроси: «Есть старый силлабус или рабочая программа этого курса? Пришлите файл —
перенесу оттуда. Нет — заполним вопросами».

### А. Перенос из старого документа

1. Получи текст:
   - docx — `uv run "${CLAUDE_PLUGIN_ROOT}/scripts/extract_text.py" "<файл.docx>"`;
   - pdf — `extract_text.py` или прочитай через Read (скан без текста — только Read);
   - `.doc` — попроси пересохранить в .docx.
2. Разложи найденное по полям схемы — таблица соответствий в
   `references/import-mapping.md`. Тексты переноси дословно, правь только явные опечатки.
3. Покажи преподавателю коротко: что нашлось (поля списком) и чего нет.
4. Пробелы и несоответствия нормам спрашивай по одному (см. шаг 3): часто нет ЦУР,
   методов, политики ИИ; РО начинаются с «знает/понимает»; часы не сходятся с кредитами.
   Старые РО с неизмеримым глаголом предложи переформулировать — покажи вариант
   «было → стало» и дождись согласия.

### Б. Интервью

Спрашивай в этом порядке, по одному вопросу; ответ сразу записывай в черновик.

| № | Вопрос | По умолчанию |
|---|---|---|
| 1 | Название дисциплины | — |
| 2 | Код по учебному плану | пусто |
| 3 | Направление (код и название), уровень | из профиля / бакалавриат |

## 3. Правила заполнения

- **Часы**: сумма видов = кредиты × 30; часы по темам в сумме = часы по видам.
  Раскладывай равномерно по неделям (лекции 2 ч/нед и т. д.), остаток — на первые недели.
- **РО**: 3–7 штук, каждый начинается с измеримого глагола Блума в 3-м лице
  («Объясняет…», «Применяет…», «Проектирует…»), один РО — одно действие.
  Никаких «знает», «понимает», «владеет». Каждый РО закрыт хотя бы одной темой.
- **Оценивание**: сумма баллов ровно 100; рубежные контроли — с неделей (`week`).
- **СРС**: у каждой темы с часами СРС — задание (`srs_task`), форма и неделя сдачи.
- **Литература**: ничего не придумывай. Источник от преподавателя или найденный в
  Crossref / OpenAlex / КиберЛенинке — `verified: true`; по памяти — `verified: false`
  (в документе будет `[НЕ ПРОВЕРЕНО]`). Оформление — ГОСТ Р 7.0.100-2018.
- Данные преподавателя не дублируй, если они есть в `profile.yaml`.
- Язык паспорта — язык преподавателя; переводы (`title_ky`, `text_en`…) добавляй,
  только когда нужен документ на другом языке.

## 4. Запиши и проверь

1. Запиши `course.yaml` по структуре образца (комментарии образца можно убрать).
2. Проверь:

   ```
   uv run "${CLAUDE_PLUGIN_ROOT}/scripts/validate_course.py" "<папка курса>/course.yaml"
   ```

3. Ошибки исправь сам, если ответ однозначен (арифметика часов), иначе спроси.
   Повторяй, пока нет ошибок.

## 5. Самопроверка и итог

Пройди чек-лист `references/checklist.md` и покажи результат списком
(✓ / ! что осталось). Затем — путь к `course.yaml` и одна следующая команда:
«соберите силлабус: `/academic-core:syllabus`».
