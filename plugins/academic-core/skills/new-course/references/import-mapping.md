# Перенос старого силлабуса / рабочей программы в `course.yaml`

Как обычно называются разделы в документах вузов КР и куда их класть.

| В документе | Поле паспорта | Заметки |
|---|---|---|
| Наименование дисциплины, код | `course.title`, `course.code` | |
| Направление / специальность, профиль | `course.program` | код + название: «710400 Программная инженерия» |
| Курс, семестр, учебный год | `course.year`, `course.semester`, `course.academic_year` | |
| Количество кредитов (ECTS) | `credits` | 1 кредит = 30 ч; встречается старая норма 1 кр = 36 ч — уточни |
| Всего часов, аудиторные, лекции, практические / семинарские, лабораторные | `hours.lectures`, `hours.practicals`, `hours.labs` | |
| СРСП, СРСП/СРМП, «под руководством преподавателя» | `hours.srsp` | |
| СРС, СРМ, самостоятельная работа | `hours.srs` | |
| Статус (обязательная / элективная / по выбору) | `course.type` | элективная → `по выбору` |
| Цикл (ГСЭ, ЕН, ПД / профессиональный) | `course.cycle` | ГСЭ → `гуманитарный`, ЕН / МЕН → `естественнонаучный`, ПД / ОПД / СД → `профессиональный` |
| Пререквизиты, постреквизиты | `course.prerequisites`, `course.postrequisites` | списком |
| Сведения о преподавателе | `teacher` | если совпадает с `profile.yaml` — не дублируй |
| Краткое описание курса, аннотация | `description` | |
| Цель, цели курса | `goals` | |
| Задачи курса | `objectives` | |
| Результаты обучения (РО, РОд), «студент должен знать / уметь / владеть» | `outcomes` | «знать/уметь/владеть» перепиши в РО с глаголом Блума — с согласия преподавателя |
| Компетенции (ОК, ИК, СЛК, ПК) | `competencies` или `outcomes[].competencies` | |
| Тематический / календарно-тематический план | `topics` | неделя, тема, часы по видам |
| Содержание дисциплины по темам | `topics[].content` | |
| Темы практических / лабораторных | `topics[].practical`, `topics[].lab` | |
| График СРС, задания СРС | `topics[].srs_task`, `srs_form`, `srs_due` | |
| Политика выставления оценок, балльно-рейтинговая система, распределение баллов | `assessment` | модуль 1 / РК1 → `midterm` с `week`; экзамен → `final` |
| Шкала оценок | `grading_scale` | совпадает с типовой — `kr_default`; иначе списком |
| Политика курса, требования, правила | `policies` | |
| Основная / дополнительная литература, интернет-ресурсы | `literature.main`, `extra`, `online` | всё перенесённое — `verified: false`, пока не проверено |

Чего обычно нет в старых документах и что спросить: ЦУР (`sdg`), активные методы
(`methods`), политика использования ИИ (`policies.ai_use`), привязка тем к РО
(`topics[].outcomes`).

Несоответствия, о которых надо сказать преподавателю:

- часы не сходятся с кредитами × 30 (старая норма 36 ч, опечатки);
- сумма баллов не 100;
- РО сформулированы через «знает / понимает / владеет»;
- тем меньше или больше, чем недель;
- литература старше 10 лет в основной — не ошибка, но стоит предложить обновить.
