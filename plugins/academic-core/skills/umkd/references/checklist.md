# Чек-лист УМКД

По выводу `build_umkd.py` и тексту `out/umkd.docx`. Каждый пункт — ✓ или ! с пояснением.

**Состав**
1. Все 10 разделов из `umkd-structure.md` на месте, по порядку, с номерами.
2. Нет разделов со статусом «нет»; «черновик» — преподаватель знает о каждом и согласен.
3. Конспект лекций — по всем темам паспорта (не «частично»).
4. Вклеенные документы (силлабус, тесты) без своих титульных листов; ключ тестов не вклеен.

**Нормы**
5. Скрипт не предупредил о часах: сумма = кредиты × 30, план по темам сходится.
6. Вопросы к экзамену покрывают все РО и все темы; есть вопросы высоких уровней Блума.
7. Вопросы к каждому рубежному контролю — только по темам до его недели.
8. Оценивание: сумма весов 100, шкала КР полная.

**Честность**
9. Литература: нет `[НЕ ПРОВЕРЕНО]`, или преподаватель знает о каждом.
10. В лекциях внутри УМКД нет неснятых `[нужен источник]` (если есть — перечислить).

**Оформление**
11. Титул: министерство, вуз, кафедра, «УТВЕРЖДАЮ», название, город, год.
12. Лист согласования: разработчик заполнен; протоколы и подписи — оставлены для руки.
13. Нет «academicAI» / «AI Lab» в документе.
