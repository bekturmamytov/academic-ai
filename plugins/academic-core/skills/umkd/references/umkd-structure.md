# Структура УМКД (типовая для вузов КР)

Состав УМКД задаёт положение вуза; образца от вуза пока нет — берём типовой состав,
общий для положений вузов КР (ГОС ВПО, кредитная система). Когда появится положение
вуза (`university/`), порядок и названия подгоняются под него.

| № | Раздел | Откуда | Если нет |
|---|---|---|---|
| — | Титульный лист с «УТВЕРЖДАЮ» (зав. кафедрой) | паспорт + профиль + `university/brand.yaml` | — |
| — | Содержание | поле TOC Word | — |
| 1 | Силлабус | `out/syllabus_<язык>.docx` (`/academic-core:syllabus`) | заглушка «нет файла» |
| 2 | Рабочая программа дисциплины: цели, место в ООП (пре-/постреквизиты, компетенции), РО по Блуму, объём часов, тематический план, образовательные технологии и ЦУР, оценивание и шкала КР, политика курса | `course.yaml` | — |
| 3 | Конспект лекций | `lectures/*.md` (`/academic-core:lecture`) | заглушка; «частично: N из M» |
| 4 | Планы практических и лабораторных занятий | `srs.yaml`, задания вида «практ/лаб» | таблица тем и часов из паспорта (черновик) |
| 5 | Самостоятельная работа студентов | `srs.yaml`, задания СРС | таблица `srs_task` из паспорта (черновик) |
| 6 | Оценочные средства: тестовые задания, вопросы к рубежным контролям, вопросы к экзамену | `out/tests_1.docx` (`/academic-core:tests`), `umkd.yaml` | вопросы по шаблону из тем и РО (черновик) |
| 7 | Глоссарий | `umkd.yaml` + «Ключевые понятия» лекций | заглушка |
| 8 | Методические указания для студентов | `umkd.yaml` → `guidelines` | типовой текст из паспорта (черновик) |
| 9 | Литература (основная, дополнительная, интернет-ресурсы) | паспорт, только `verified: true` чисто | непроверенные — с `[НЕ ПРОВЕРЕНО]` |
| 10 | Лист согласования: разработчик, протокол кафедры, зав. кафедрой, УМК факультета | профиль | поля для подписей |

Отдельными файлами рядом с УМКД (в docx не вклеиваются): РУП `rup.xlsx`, банк тестов
`tests.xlsx` и ключ `tests_key.docx`, импорт в Moodle `tests.gift`, презентации
`out/slides/*.pptx`.

## Формат umkd.yaml

```yaml
glossary:
  - term: "Нормализация"
    definition: "Приведение схемы базы данных к нормальным формам для устранения избыточности."
midterm_questions:          # ключ — номер рубежного контроля по порядку в assessment
  1:
    - "Объясните, чем первичный ключ отличается от внешнего."
  2:
    - "Сравните уровни изоляции транзакций."
exam_questions:
  - "Спроектируйте схему базы данных для учёта библиотеки до 3НФ."
guidelines: |
  ## Как работать с курсом
  1. До лекции ответьте на вопросы для подготовки…
```

Рубежные контроли скрипт находит в `assessment` паспорта: элементы с `week` и словом
«рубеж» / «модуль» / «аралык» / «midterm» в названии.

## Проверки (по нормам)

- Часы: сумма видов = кредиты × 30; итог тематического плана = часы по видам.
- РО: глагол Блума, у каждого РО есть темы; вопросы к экзамену покрывают все РО.
- Оценивание: веса = 100; шкала КР 87–100 A … 0–60 F.
- Литература: в чистовике только проверенные источники.
