# Чек-лист теста

Каждый пункт — ✓ или ! с пояснением.

**Покрытие** (скрипт + глазами)
1. Каждая тема выбранного диапазона имеет вопрос; темы с большим числом часов — больше вопросов.
2. Каждый РО имеет вопрос; уровень Блума вопроса не выше уровня его РО.
3. Не больше половины вопросов на запоминание; есть применение, анализ, оценка.
4. Сложность: примерно 30 / 50 / 20 (базовый / средний / повышенный).

**Ключи**
5. У каждого вопроса есть ключ; для открытых — эталон или критерии.
6. Ключ проверен по содержанию курса (лекции, учебник), а не по памяти;
   сомнительные — помечены и показаны преподавателю.
7. Сверены 2–3 ответа варианта 1: буква в `tests_key.docx` указывает на верный вариант бланка.

**Качество вопросов**
8. Нет дублей и почти-дублей (один и тот же факт другими словами — тоже дубль).
9. Вопрос понятен без контекста; одно утверждение; без двойного отрицания.
10. Дистракторы правдоподобны: типичные ошибки студентов, та же тема, та же форма и длина.
11. Правильный ответ не выделяется длиной, точностью или словами из вопроса.
12. Нет «все перечисленные / ни один из перечисленных»; нет «всегда / никогда» как подсказки.
13. Верно/неверно — утверждение однозначно истинно или ложно.
14. Соответствие — левые и правые элементы одного рода, ≥ 3 пар.

**Файлы**
15. Собраны xlsx, бланки всех вариантов, ключ, GIFT, Moodle XML.
16. В бланках нет ответов; ключ — отдельным файлом.
17. Нет упоминаний academicAI, AI Lab, Claude.
