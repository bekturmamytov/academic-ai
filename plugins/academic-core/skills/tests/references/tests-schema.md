# Банк тестов `tests.yaml` — схема

Лежит в папке курса рядом с `course.yaml`. Образец — `templates/tests.example.yaml`
(18 вопросов по курсу «Базы данных», все типы).

## Верхний уровень

| Поле | Тип | По умолчанию | Правило |
|---|---|---|---|
| `schema` | int | 1 | версия схемы |
| `title` | строка | «Тест» | название на бланке: «Рубежный контроль 1», «Итоговый тест» |
| `language` | `ru` \| `ky` \| `en` | язык курса | язык меток бланка |
| `course` | путь | `course.yaml` рядом | паспорт курса относительно этого файла |
| `variants` | int 1–30 | 2 | сколько вариантов бланка |
| `per_variant` | int | все вопросы | вопросов в варианте; меньше банка — выбор поровну по темам |
| `seed` | int / строка | 0 | одинаковый — одинаковые варианты при пересборке |
| `time_minutes` | int | — | время на тест, пишется в инструкции бланка |
| `topics` | список int | все темы | недели, которые тест должен покрыть (рубежный контроль 1 — `[1, 2, 3, 4, 5, 6, 7]`); покрытие РО — по РО этих тем |
| `questions` | список | обяз. | вопросы |

## Вопрос

| Поле | Тип | | Правило |
|---|---|---|---|
| `id` | строка | обяз. | уникальный: `Q01`… |
| `topic` | int | обяз. | неделя темы из `course.yaml` → `topics[].week` |
| `outcome` | строка | обяз. | id РО из `course.yaml` → `outcomes[].id` |
| `type` | тип | обяз. | `single` \| `multiple` \| `truefalse` \| `matching` \| `short` \| `open` |
| `difficulty` | | обяз. | `easy` (базовый) \| `medium` (средний) \| `hard` (повышенный) |
| `bloom` | | обяз. | `remember` \| `understand` \| `apply` \| `analyze` \| `evaluate` \| `create` |
| `text` | строка | обяз. | формулировка; без повторов в банке |
| `options` | список строк | для выбора | ≥ 4, без повторов |
| `answer` | см. ниже | обяз. | ключ |
| `pairs` | список `[левое, правое]` | для matching | ≥ 3 пары, без повторов |
| `points` | число > 0 | 1 | баллы за вопрос |

### `answer` по типам

| Тип | Что такое | `answer` |
|---|---|---|
| `single` | один правильный из ≥ 4 | текст правильного варианта (совпадает с одним из `options`) |
| `multiple` | несколько правильных | список текстов правильных вариантов (не все варианты) |
| `truefalse` | верно / неверно | `true` или `false` |
| `matching` | соответствие | не нужен — ключ в `pairs` (правое перемешивается на бланке) |
| `short` | краткий ответ | строка или список допустимых написаний: `["3НФ", "3 НФ"]` |
| `open` | развёрнутый ответ | эталон ответа или критерии оценки (для ключа и Moodle «информация для оценщика») |

Ключ пишется **текстом**, а не буквой: варианты перемешиваются, буквы в каждом
бланке свои — скрипт сам расставит их в ключе.

## Что собирается

- `tests.xlsx`: «Банк вопросов» (все поля + варианты с буквами + ключ),
  «Покрытие» (СЧЁТЕСЛИ по неделям, РО, типам, сложности, Блуму), «Варианты» (порядок
  вопросов и ключ по каждому варианту).
- `tests_<N>.docx`: шапка (вуз, курс, название, вариант, ФИО/группа/дата, инструкция),
  вопросы с подсказкой типа и баллов, места для ответа.
- `tests_key.docx`: по вариантам — № вопроса, ID, ответ (буквы / Верно / пары / эталон), баллы, сумма.
- `tests.gift`: `$CATEGORY: $course$/top/<курс>/Тема NN. <название>`; спецсимволы
  `~ = # { } :` экранируются `\`; multiple — веса `%33.33333%`, неверные —
  отрицательные; truefalse — `{TRUE}`/`{FALSE}`; short — `{=a =b}`; matching —
  `{=левое -> правое}`; open — `{}` (эссе).
- `tests_moodle.xml`: `multichoice` (single true/false), `truefalse`, `matching`,
  `shortanswer`, `essay` (с `graderinfo`); `defaultgrade` = `points`; метки
  `РО1`, `bloom-apply`, `difficulty-medium` — по ним в Moodle удобно собирать
  случайные вопросы.

## Проверки `build_tests.py --check`

| Проверка | Уровень |
|---|---|
| нет id / повтор id, неизвестный type / difficulty / bloom | ошибка |
| повтор текста вопроса (без учёта регистра и пробелов) | ошибка |
| выбор: < 4 вариантов, повтор вариантов, ключ не из вариантов, single с ≥ 2 ключами, multiple — все верные | ошибка |
| truefalse без `true/false`; matching < 3 пар или повторы; short / open без ответа | ошибка |
| тема или РО не из `course.yaml` | ошибка |
| тема или РО без вопросов | предупреждение |
| нет сложных вопросов; > 70% одного уровня сложности; > 50% на запоминание | предупреждение |
| «все / ни один из перечисленных»; правильный ответ вдвое длиннее дистракторов | предупреждение |
| multiple с одним правильным | предупреждение |
