# Тесты: банк вопросов, бланки, Moodle

Вопросы пишешь ты в `tests.yaml` рядом с `course.yaml`; файлы собирает скрипт.
Схема банка — `references/tests-schema.md`, образец —
`${CLAUDE_PLUGIN_ROOT}/skills/tests/templates/tests.example.yaml`, правила хороших
вопросов и чек-лист — `references/checklist.md`. Вопросы к преподавателю — по одному.

## 1. Паспорт и задача

1. Найди `course.yaml` (нет — пройди `academic-core:new-course`). Из него берутся
   темы (недели) и РО — без паспорта покрытие не проверить.
2. Спроси по одному, предлагая значение по умолчанию:
   - для чего тест: рубежный контроль 1 (темы до его недели), рубежный 2, итоговый
     (все темы), тест по одной теме (итоговый);
   - сколько вопросов в варианте и сколько вариантов (по правилам вуза —
     `university/settings.yaml` → `tests.questions_per_variant`, `tests.variants`; нет — 20 и 2);
   - типы вопросов (смесь: в основном один ответ, плюс несколько ответов,
     верно/неверно, соответствие, 1–2 открытых);
   - время на тест (40 мин); нужна ли выгрузка в Moodle (по умолчанию — как в
     `tests.moodle` настроек вуза; вуз без Moodle — не спрашивай, файлы Moodle не нужны).
3. Есть лекции (`lectures/`), методички или старые тесты преподавателя — опирайся на
   них: вопросы должны проверять то, что давали на занятиях.

## 2. Составь банк

Запиши `<папка курса>/tests.yaml`. Если `tests.yaml` уже есть с другим банком — новый
назови по контролю: `tests_rk1.yaml`, `tests_rk2.yaml`, `tests_final.yaml`.
Банк больше варианта примерно в 1,5 раза, чтобы варианты различались. Тест на часть
курса — укажи недели в `topics: [1, …, 7]`, покрытие проверится только по ним.

- **Покрытие**: каждая тема из выбранного диапазона и каждый РО — хотя бы один
  вопрос; больше вопросов на темы с большим числом часов.
- **Уровни**: Блум — не больше половины на запоминание, есть применение и анализ;
  уровень вопроса не выше уровня его РО. Сложность — примерно 30% базовых, 50%
  средних, 20% повышенных.
- **Варианты ответа**: для выбора — не меньше 4; дистракторы правдоподобные
  (типичные ошибки студентов), одной длины и формы с правильным; без «все
  перечисленные» и без подсказок в формулировке.
- **Ключ** у каждого вопроса: для открытого — эталон или критерии оценки.
- Только факты курса; не выдумывай цифры и цитаты. Сомневаешься в правильности
  ключа — отметь и спроси преподавателя.
- Язык вопросов — язык курса (`language`), один язык на банк.

## 3. Проверка

```
uv run "${CLAUDE_PLUGIN_ROOT}/scripts/build_tests.py" "<папка курса>/tests.yaml" --check
```

Скрипт проверяет: id и тексты без повторов, ключ есть и совпадает с вариантом,
≥ 4 варианта, пары соответствия, темы и РО есть в паспорте, покрытие тем и РО,
баланс сложности и Блума, подозрительные дистракторы. Ошибки исправь; предупреждения
о покрытии — дополни банк или объясни преподавателю, почему тема не покрыта
(например, тест только на рубежный контроль 1).

## 4. Сборка

```
uv run "${CLAUDE_PLUGIN_ROOT}/scripts/build_tests.py" "<папка курса>/tests.yaml"
```

В `<папка курса>/out/`:

| Файл | Что |
|---|---|
| `tests.xlsx` | банк с ключом; лист «Покрытие» (формулы СЧЁТЕСЛИ по темам, РО, типам, сложности, Блуму); лист «Варианты» |
| `tests_1.docx`, `tests_2.docx`… | бланки вариантов: вопросы и ответы перемешаны, без ключа |
| `tests_key.docx` | ключ по каждому варианту с баллами — **не раздавать студентам** |
| `tests.gift` | импорт в Moodle (формат GIFT, категории по темам) |
| `tests_moodle.xml` | импорт в Moodle (Moodle XML, с баллами и метками РО / Блум / сложность) |

Тот же `seed` — те же варианты при пересборке; новые варианты — смени `seed`.

Что выгружать — по правилам вуза (`tests.formats`; при `tests.moodle: false` файлы
Moodle не собираются). Попросили явно — флаги главнее: `--formats docx,gift`,
`--variants 4`, `--per-variant 25`.

## 5. Самопроверка

Пройди `references/checklist.md`: покрытие, ключи, дубли, качество дистракторов
(перечитай каждый вопрос с выбором глазами студента), открой бланк и ключ
(`extract_text.py`) и сверь 2–3 ответа варианта 1 по ключу. Покажи итог списком ✓ / !.

## 6. Итог

Пути к файлам, напоминание «ключ хранить отдельно» и как загрузить в Moodle:
«Банк вопросов → Импорт → формат GIFT (или Moodle XML) → файл `tests.gift`»
(версия Moodle вуза — `tests.moodle_version`; если пункты меню в ней другие, скажи об этом).
Одна следующая команда — например, `/academic-core:syllabus`, если силлабус ещё не собран.
