# Структура учебно-методического пособия

Типовой состав учебного издания вуза (ГОСТ 7.60 — виды изданий, ГОСТ Р 7.0.4 —
выходные сведения). Требования конкретного вуза и издательства — главнее.

## Обязательные элементы

| Элемент | Что | Где в сборке |
|---|---|---|
| Обложка / титул | министерство, вуз, кафедра; авторы; название; вид издания; город, год | `manual.typ` → обложка |
| Оборот титула | УДК, ББК, авторский знак; «Рекомендовано к изданию …»; рецензенты; библиографическое описание с числом страниц; аннотация; ISBN; © авторы, © вуз | `manual.typ` → вторая страница |
| Содержание | главы и параграфы с номерами страниц | `outline()` |
| Введение | цель, адресат, связь с дисциплиной и РО, как пользоваться | глава `chapters/00-vvedenie.md` |
| Главы | теория → примеры → вопросы → задания | `chapters/NN-*.md` |
| Заключение | итоги, куда двигаться дальше | последняя глава |
| Список литературы | ГОСТ Р 7.0.100-2018, только проверенные источники | `literature` |
| Приложения | таблицы, образцы, справочные данные | глава «Приложение А…» |

## Виды и акценты

- **Учебно-методическое пособие** — теория + методика: задания, примеры решений,
  критерии оценки, вопросы. Объём главы — 8–20 страниц A5.
- **Учебное пособие** — полнее теория, меньше методики; часто требует грифа.
- **Методические указания** (к лабораторным, СРС, курсовой) — цель, порядок
  выполнения, требования к отчёту, критерии, варианты заданий; теории — минимум.
- **Курс лекций** — лекции курса, сведённые в единый текст.

## Вёрстка (делает шаблон)

| | A5 | A4 |
|---|---|---|
| Поля | 18 / 20 / 20 / 15 мм | 20 / 20 / 30 / 15 мм |
| Кегль | 10,5 pt | 13 pt |
| Абзацный отступ | 1 см | 1,25 см |

Выравнивание по ширине с переносами; заголовок главы с новой страницы, по центру,
прописными; нумерация страниц внизу по центру, на обложке и обороте не показывается.

## Честность

- УДК, ББК, ISBN, авторский знак — только от библиотеки / издательства.
- Рецензенты — реальные люди, согласившиеся рецензировать; не подставлять.
- Источники — проверенные; данные исследований автора — только его.
