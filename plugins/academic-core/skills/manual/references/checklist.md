# Чек-лист пособия

Каждый пункт — ✓ или ! с пояснением.

**Состав**
1. Обложка: министерство, вуз, кафедра, авторы, название, вид издания, город, год.
2. Оборот титула: УДК, ББК (или прочерк + напоминание), «Рекомендовано к изданию…»,
   рецензенты, библиографическое описание с числом страниц, аннотация, ISBN, ©.
3. Содержание с номерами страниц; введение, главы, заключение, литература.
4. В каждой главе — вопросы для самоконтроля; в УМП — задания.

**Содержание**
5. Текст опирается на материалы преподавателя; расхождения с ними названы.
6. Термины единые во всех главах; нет «аудиторных» остатков из лекций.
7. Нет цифр, цитат, дат без источника; все `[нужен источник]` / `[нужны ваши данные]` перечислены автору.

**Литература и выходные данные**
8. Литература — проверенная, по ГОСТ Р 7.0.100-2018; нет `[НЕ ПРОВЕРЕНО]` (или автор знает).
9. УДК, ББК, ISBN не придуманы; рецензенты — реальные, указанные автором.

**Вёрстка**
10. PDF собран: обложка без переносов, таблицы и рисунки в полях, заголовки глав с новой страницы.
11. docx тоже есть (для редакции); нет «academicAI» / «AI Lab».
