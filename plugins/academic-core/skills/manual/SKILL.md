# Учебно-методическое пособие

Пособие — издание под именем преподавателя. Содержание — **его материалы** (лекции
курса, конспекты, статьи, задания); ты — редактор и соавтор: структура, связность,
вопросы и задания, оформление. Фактов и данных не придумываешь.

Говори на языке преподавателя (ru или ky), вопросы — по одному, с вариантом по умолчанию.

## 1. Что издаём

Спроси по одному:

1. Вид издания: учебно-методическое пособие / учебное пособие / методические указания
   (к лабораторным, к СРС, к курсовой) / курс лекций. (учебно-методическое пособие)
2. Название и для кого (направление, курс).
3. Из чего: лекции курса (`lectures/*.md`), файлы преподавателя
   (`uv run "${CLAUDE_PLUGIN_ROOT}/scripts/extract_text.py" "<файл>"`), или всё вместе.
4. Формат: A5 (типовой для пособий) или A4. (A5)
5. Авторы, рецензенты (ФИО, степень, должность, место работы), кем рекомендовано к
   изданию — если пока нет, оставим места.

Папка: `<папка курса>/manual/` (или отдельная папка, если пособие не к одному курсу).

## 2. Главы `manual/chapters/NN-<slug>.md`

Структура издания и требования — `references/manual-structure.md`. Коротко:

- Введение (цель, для кого, как пользоваться, связь с РО и ЦУР курса).
- Главы `# Глава N. …` с параграфами `## N.1. …`; в конце главы —
  `## Вопросы для самоконтроля` и, для УМП, `## Задания`.
- Заключение; приложения при необходимости.
- Разметка — как у лекций (заголовки, списки, таблицы, `![подпись](путь)` для рисунков
  преподавателя, `\pagebreak`).
- Из лекций: убери «аудиторное» (вопросы перевёрнутого класса, тайминг), сделай связный
  текст, добавь переходы между главами, единые термины.
- Честность: цифры, цитаты и даты без источника — `[нужен источник]`; данных
  исследований не придумывай — `[нужны ваши данные]`. Все пометки перечисли автору.

## 3. `manual/manual.yaml`

Образец — `templates/manual.example.yaml`. Поля: `kind`, `title`, `subtitle`, `authors`,
`udk`, `bbk`, `author_sign`, `isbn`, `reviewers`, `recommended`, `annotation`, `city`,
`year`, `paper` (a5 | a4), `chapters` (пути к главам), `literature`.

- **УДК, ББК, авторский знак, ISBN не придумывай** — их выдаёт библиотека вуза или
  издательство. Пусто → на обороте титула прочерк, скрипт напомнит.
- `recommended` пусто → «Рекомендовано к изданию Учёным советом ___ (протокол № ___)».
- Аннотация — 3–5 предложений: о чём, для кого, чем полезно.
- Литература — из паспорта курса (`verified: true`) и проверенная преподавателем, по
  ГОСТ Р 7.0.100-2018. Нет `literature` в `manual.yaml` — берётся вся литература паспорта.

## 4. Сборка

```
uv run "${CLAUDE_PLUGIN_ROOT}/scripts/build_manual.py" "<папка>/manual/manual.yaml"
```

Результат: `out/manual.pdf` (Typst: Times New Roman или свободный serif — Liberation
Serif / PT Serif / DejaVu Serif; обложка, оборот титула с числом страниц, оглавление,
главы, литература) и `out/manual.docx` (то же для редактора издательства).
Шаблон вёрстки — `templates/manual.typ` (в папке этого skill).

Typst не установлен — скрипт соберёт только docx и скажет об этом; предложи
`/academic:setup` (там ставится Typst). Только docx сразу: флаг `--no-pdf`.

Посмотри PDF (Read по страницам или `pdftoppm`): обложка без переносов, таблицы не
вылезают, оглавление с номерами страниц.

## 5. Самопроверка и итог

Пройди `references/checklist.md`, покажи результат списком. Напомни, что нужно для
издания: рецензии, выписка о рекомендации, УДК/ББК/ISBN от библиотеки.

Затем — пути к PDF и docx и одна следующая команда, например «внесите пособие в
УМКД: `/academic-core:umkd`».
