# РУП дисциплины: состав

В КР рабочая (учебная) программа дисциплины составляется по ГОС ВПО и учебному
плану направления; форму утверждает вуз. Общий состав, по которому собирает
`build_rup.py`; положение вуза — приоритет.

## rup.xlsx

### Лист «Распределение часов»

| Строка | Значение |
|---|---|
| Лекции, Практические, Лабораторные, СРСП, СРС | часы из `hours` (вводимые значения) |
| Доля | `=Bn/Итого`, формат % |
| Аудиторные | `=SUM(Л:Лаб)` |
| СРСП + СРС | `=SUM(СРСП:СРС)` |
| Итого | `=SUM(все виды)` |
| Кредиты (итого / 30) | `=Итого/30` |
| Кредиты по учебному плану | `credits` |
| Сверка | `=IF(Итого=Кредиты*30,"сходится","НЕ сходится")` |

### Лист «Тематический план»

Колонки: неделя, тема, Л, П, Лаб, СРСП, СРС, Итого (`=SUM` по строке), РО,
лабораторная / практическое, контроль. Внизу: «Итого» (`=SUM` по колонкам),
«По паспорту» (ссылки на лист часов), «Сверка» (✓ / ≠).

### Лист «Календарный график контроля»

Строки — виды контроля из `assessment`; колонки — вид, тип (текущий / рубежный /
итоговый), форма, недели 1…N, «Сессия», «Итого» (`=SUM`). Внизу «Итого» по неделям и
сверка суммы со 100. Баллы: `week`/`weeks` — в эти недели; `final` без недели — в
сессию; `current` без недели — поровну на все недели.

## Рабочая программа дисциплины (docx, `--docx`)

| № | Раздел | Откуда |
|---|---|---|
| — | Титульный лист «РАБОЧАЯ ПРОГРАММА ДИСЦИПЛИНЫ» | `university/`, `profile.yaml`, `course` |
| 1 | Цели и задачи дисциплины | `goals`, `objectives` |
| 2 | Место дисциплины в структуре ООП | `course.cycle`, `type`, `program`, пре- и постреквизиты |
| 3 | Результаты обучения и компетенции | `outcomes`, `competencies` |
| 4 | Объём дисциплины и виды учебной работы | `hours`, `credits` |
| 5 | Содержание дисциплины по темам | `topics[].title/content/lab/practical` |
| 6 | Тематический план | `topics` (часы по видам, РО) |
| 7 | Учебно-методическое обеспечение самостоятельной работы | `topics[].srs_task/srs_form/srs_due` |
| 8 | Оценочные средства | `assessment`, `grading_scale` |
| 9 | Литература | `literature` (непроверенное — `[НЕ ПРОВЕРЕНО]`) |
| 10 | Согласование | составитель, заседание кафедры, зав. кафедрой |

Не собирается автоматически (нет данных в паспорте) — дописывает кафедра по
форме вуза: материально-техническое обеспечение (аудитории, ПО), фонд оценочных
средств целиком (тесты — skill `tests`), лист изменений и дополнений.

Оформление docx — как у силлабуса: Times New Roman 14, интервал 1,5, поля 30/15/20/20.
