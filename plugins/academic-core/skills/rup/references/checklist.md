# Чек-лист РУП

Каждый пункт — ✓ или ! с пояснением.

**rup.xlsx**
1. Три листа: «Распределение часов», «Тематический план», «Календарный график контроля».
2. Итоги — формулы (`=SUM`, `=IF`), а не числа; кредиты считаются как итого / 30.
3. Итого часов = кредиты × 30 (строка «Сверка» → «сходится»).
4. Тематический план: строка «Итого» по каждому виду совпадает с «По паспорту» (✓).
5. Недель в плане столько же, сколько в семестре; у каждой темы есть РО.
6. График контроля: итог = 100; рубежные — в своих неделях, итоговый — в сессии.

**Рабочая программа (docx)**
7. Все 10 разделов из `structure.md` на месте, по порядку.
8. Место в ООП: цикл, статус, пре- и постреквизиты указаны.
9. Содержание по темам — не только названия (есть `content`), у лабораторных/практик — темы.
10. Таблица объёма совпадает с Excel.
11. Литература: непроверенное помечено `[НЕ ПРОВЕРЕНО]` или убрано (`--final`).
12. Нет выдуманных данных (протоколы, даты, аудитории); нет academicAI / AI Lab / Claude.
