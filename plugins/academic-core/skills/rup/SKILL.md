# РУП: рабочая учебная программа дисциплины

**Что здесь значит РУП.** В вузах КР «РУП» говорят о двух вещах: рабочий учебный
план направления (все дисциплины по семестрам — его ведёт учебный отдел) и рабочая
учебная программа **одной дисциплины**. Этот skill делает второе:

- `out/rup.xlsx` — три листа: «Распределение часов», «Тематический план»,
  «Календарный график контроля». Итоги — формулами Excel (СУММ), со сверкой с
  паспортом: поменял часы в таблице — итог пересчитался и видно, сходится ли;
- `out/rup_<lang>.docx` (флаг `--docx`) — «Рабочая программа дисциплины»: цели,
  место в ООП, компетенции и РО, объём, содержание по темам, тематический план,
  обеспечение СРС, оценочные средства, литература, согласование.

Если преподаватель имел в виду учебный план направления — скажи, что его составляет
учебный отдел, а отсюда можно взять часы своей дисциплины.

Структура и нормы — `references/structure.md`, чек-лист — `references/checklist.md`.
Вопросы — по одному, на языке преподавателя.

## 1. Паспорт курса

Найди `course.yaml` (как в skill `academic-core:syllabus`). Нет — пройди
`academic-core:new-course`, затем вернись.

## 2. Проверка

```
uv run "${CLAUDE_PLUGIN_ROOT}/scripts/validate_course.py" "<папка курса>/course.yaml"
```

Ошибки — исправь (арифметику сам, содержание — спросив). Для РУП особенно важны:

- часы по видам = кредиты × 30, часы по темам = часы по видам;
- у рубежных контролей указана неделя (`week`), у итогового — `type: final`;
- для рабочей программы (`--docx`) — `content` у тем (краткое содержание) и `lab` /
  `practical` (темы занятий). Нет — предложи черновик по названиям тем и утверди
  с преподавателем; без них раздел «Содержание» будет только из названий тем.

## 3. Сборка

```
uv run "${CLAUDE_PLUGIN_ROOT}/scripts/build_rup.py" "<папка курса>/course.yaml" --docx
```

- Без `--docx` — только Excel.
- `--lang ru|ky|en` — язык; переводы полей как в силлабусе (`title_ky`, `content_ky`…).
- `--final` — в docx без непроверенной литературы.
- Текущий контроль без недель скрипт делит поровну по всем неделям (будут дроби,
  например 1,33). Если преподаватель хочет целые баллы — задай `weeks` или раздели
  контроль на несколько строк в `assessment`.

## 4. Самопроверка

1. Excel: открой `rup.xlsx` (skill `xlsx` или openpyxl) и проверь, что формулы на месте:
   итог по видам `=SUM(...)`, кредиты `=итого/30`, строка «Сверка» в тематическом
   плане, итог графика контроля = 100. Значения формул без Excel не посчитаны — это
   нормально, их считает Excel / LibreOffice при открытии.
2. Docx: прочитай текст (`extract_text.py`) и пройди `references/checklist.md`.
3. Покажи итог списком ✓ / !. Ошибка в данных — правь `course.yaml` и пересобирай.

## 5. Итог

Пути к файлам и одна следующая команда: «банк тестов по темам и РО:
`/academic-core:tests`». В документах — никаких упоминаний academicAI, AI Lab, Claude.
