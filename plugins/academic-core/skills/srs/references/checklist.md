# Чек-лист заданий СРС и практических

Каждый пункт — ✓ или ! с пояснением.

**Соответствие паспорту**
1. Задание есть у каждой темы с часами СРС (и практических / лабораторных, если их делали).
2. Часы заданий = часы тем в паспорте; часы СРС в сумме = `hours.srs` (скрипт не предупредил).
3. РО заданий — коды из паспорта; уровень задания соответствует глаголу Блума РО.
4. Сроки — недели внутри семестра, не раньше недели темы.
5. Баллы по видам сходятся с весами `assessment` паспорта.

**Качество заданий**
6. У каждого задания есть цель, конкретное задание, шаги, форма сдачи, срок.
7. Рубрика: 3–5 критериев, у каждого баллы и все 4 уровня с наблюдаемыми признаками.
8. Есть активные форматы (кейс, PBL, peer review); где уместно — ЦУР.
9. Задания защищены от списывания и сдачи сгенерированного текста (вариант, защита, промежуточные артефакты).
10. Студенту даётся задание и критерии — готовых решений в документе нет.

**Честность и файл**
11. Литература только из паспорта; `[НЕ ПРОВЕРЕНО]` нет или преподаватель знает о каждом.
12. `out/srs.docx` создан; нет «academicAI» / «AI Lab».
