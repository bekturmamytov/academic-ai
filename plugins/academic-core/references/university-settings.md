# Настройки вуза — `university/settings.yaml`

Как подстроить документы под правила своего вуза: форма силлабуса, шкала БРС,
поля и шрифт, кто утверждает, стиль ссылок, Moodle. Файл лежит в папке
`university/` рабочей папки (рядом с `profile.yaml`); скрипты ищут её от папки
курса или работы вверх по дереву.

- Образец со всеми ключами: `plugins/academic-core/templates/settings.example.yaml`.
- Заполнить по образцам вуза: `/academic-core:university`.
- Проверить: `uv run "${CLAUDE_PLUGIN_ROOT}/scripts/university_check.py" "<рабочая папка>"` —
  что отличается от норм КР, ошибки и предупреждения; `--yaml` — все действующие значения.
- Загрузчик: `scripts/settings.py` (одинаковая копия в `academic-research/scripts/`).

## Порядок важности

```
course.yaml / work.yaml  >  university/settings.yaml  >  university/brand.yaml  >  нормы КР
```

- Ключа нет или он пустой (`""`, `{ru: "", ky: ""}`) — действует уровень ниже.
- Словари вглубь сливаются (`margins_mm: {left: 25}` меняет только левое поле);
  списки и тексты `{ru, ky, en}` заменяются целиком.
- Текст `{ru, ky, en}` без нужного языка — берётся `ru` (`university_check` предупредит).
- `brand.yaml` (старый формат: `name`, `name_ky`, `name_en`, `logo`, `color`) читается
  по-прежнему и заполняет `university.name*` и `brand.*`, если их нет в `settings.yaml`.
  Пока `settings.yaml` нет, логотип из `brand.yaml` ставится на титул, как раньше.
- Ошибка в настройках (неверный тип, шкала с дырой, баллы ≠ 100) останавливает сборку
  с сообщением по-русски, где назван ключ. Неизвестный ключ — только предупреждение.

## Ключи

### `university` — вуз

| Ключ | По умолчанию | Где действует |
|---|---|---|
| `name`, `name_ky`, `name_en` | пусто → `profile.yaml` → `university` | титулы всех docx, шапка тестов и отчётов, слайды, научные работы |
| `short` | пусто | справочно (для подсказок skills) |
| `city` | пусто → `profile.yaml` → `city` | строка «город, год» на титулах, слайды, пособие, научные работы |
| `type` | `state` | `private` — видео-лекция предупредит о Company License Remotion |
| `ministry` `{ru, ky, en}` | строка Минобрнауки КР | первая строка титула (core, research, пособие) |

### `brand` — фирменный стиль

| Ключ | По умолчанию | Где действует |
|---|---|---|
| `logo` | `logo.png` (файл в `university/`) | презентации; титул docx — если `document.title_page_logo: true` |
| `color` | `#1F4E79` | акцент презентаций и видео-лекций (`slides.yaml` → `accent` главнее) |

### `document` — оформление Word

| Ключ | По умолчанию | Где действует |
|---|---|---|
| `font` | Times New Roman | все docx core и research; проверка `check_format.py` |
| `size` | 14 | основной текст и заголовки; проверка |
| `table_size` | 12 | текст в таблицах |
| `line_spacing` | 1.5 | основной текст; проверка |
| `indent_cm` | 1.25 | абзацный отступ; проверка |
| `margins_mm` `{left, right, top, bottom}` | 30 / 15 / 20 / 20 | поля всех docx; проверка и `--fix` |
| `page_numbers` | `bottom-center` | `bottom-right`, `top-center`, `top-right`, `none` |
| `title_page_logo` | `false` | логотип `brand.logo` над шапкой титула (силлабус, РУП, УМКД, лекции, СРС) |

Бланки тестов остаются компактными (12 pt, интервал 1,0), шрифт — из настроек.

### `approval` — «УТВЕРЖДАЮ» / «СОГЛАСОВАНО» (силлабус, РУП, УМКД)

| Ключ | По умолчанию | Где действует |
|---|---|---|
| `enabled` | `true` | `false` — титул без «УТВЕРЖДАЮ» |
| `role` `{ru, ky, en}` | Заведующий кафедрой | должность в «УТВЕРЖДАЮ» и в подписи в конце силлабуса / РУП |
| `name` | пусто → линия для подписи | «________ И.И. Иванов» |
| `agreed` | `[]` | `[{role: {ru: Декан факультета}, name: ""}]` — блок «СОГЛАСОВАНО» слева от «УТВЕРЖДАЮ» |
| `protocol` | `true` | строки «Рассмотрен и одобрен на заседании кафедры… Протокол №…» в конце силлабуса и РУП |

### `grading` — оценивание

| Ключ | По умолчанию | Где действует |
|---|---|---|
| `credit_hours` | 30 | проверка «часы = кредиты × N» (`validate_course`, силлабус, РУП, УМКД), формулы xlsx РУП |
| `scale` | типовая шкала КР (A 87–100 … F 0–60) | шкала в силлабусе, УМКД, отчёт по дисциплине; курс с `grading_scale: kr_default` или без него берёт её |
| `assessment_template` | текущий 30, РК1 15 (нед. 8), РК2 15 (нед. 15), экзамен 40 | предложение БРС в `/academic-core:new-course`; `[]` — команда спросит |

Шкала: строки `{min, max, letter, grade: {ru, ky, en}}`, целые баллы, вместе ровно
0–100 без пропусков и наложений. В отчёте по дисциплине «успеваемость» — доля с баллом
от нижней положительной строки (`min > 0`), «качество» — от нижней строки «хорошо».

### `syllabus` — форма силлабуса

| Ключ | По умолчанию | Где действует |
|---|---|---|
| `hide_sections` | `[]` | убрать разделы: `sdg`, `methods` (оба — раздел целиком), `srs`, `calendar` (тематический план), `policies`, `literature`; нумерация идёт без дыр |
| `policies` `{attendance, late_work, academic_integrity, ai_use}` | пусто | политика по умолчанию для всех курсов; текст в `course.yaml` главнее |
| `extra_sections` | `[]` | `[{title: {ru: …}, text: {ru: …}}]` — свои разделы перед подписями; абзацы — через пустую строку |

### `tests` — тесты

| Ключ | По умолчанию | Где действует |
|---|---|---|
| `formats` | `[docx, xlsx, gift, moodle_xml]` | что выгружает `build_tests.py` (флаг `--formats` главнее) |
| `variants` | 2 | вариантов, если в `tests.yaml` нет `variants` (флаг `--variants` главнее) |
| `questions_per_variant` | 0 — все вопросы банка | вопросов в варианте, если в `tests.yaml` нет `per_variant`; банк меньше — весь банк |
| `moodle` | `true` | `false` — GIFT и Moodle XML не выгружаются, пока их не попросить (`--formats gift`) |
| `moodle_version` | пусто | справочно: для инструкции импорта в skill `tests` |

### `research` — научные и студенческие работы

| Ключ | По умолчанию | Где действует |
|---|---|---|
| `citation_style` | `gost` | `work.yaml` без `citation_style` (`gost` · `apa` · `ieee`) |
| `bib_order` | `auto` | `auto` — ieee по упоминанию, остальные по алфавиту; `alpha` / `cite` — для всех работ без `bib_order` |
| `thesis_pages` | `bachelor: [40, 60]`, `master: [60, 90]` | `status.py` сверяет объём; skills `thesis`, `student-work` берут в задание, методичку, критерии. Можно добавить `coursework` (курсовая) и `phd` (кандидатская) |
| `plagiarism_min` | 75 | порог оригинальности, % — в методичке, критериях и рецензии (`student-work`) |

### `manual` — учебно-методическое пособие

| Ключ | По умолчанию | Где действует |
|---|---|---|
| `paper` | `a5` | формат PDF, если в `manual.yaml` нет `paper` |
| `approval_body` `{ru, ky, en}` | Учёный совет | строка «Рекомендовано к изданию…» на обороте титула, если в `manual.yaml` нет `recommended` |

### `environment` — окружение

| Ключ | По умолчанию | Где действует |
|---|---|---|
| `os` | `[windows, macos]` | `/academic:setup` подсказывает команды установки для этих ОС |
| `languages` | `[ru, ky]` | язык документов, если нет `language` в `profile.yaml` / паспорте (первый в списке); предупреждения о недостающих переводах |

## Что вуз пишет в положениях → куда

| В положении / образце | Ключ |
|---|---|
| «Поля: левое 30 мм…», «шрифт Times New Roman 14, интервал 1,5» | `document.*` |
| «Утверждаю: проректор по УР», «Согласовано: декан» | `approval.role`, `approval.agreed` |
| Таблица перевода баллов в оценки, «1 кредит = 30 ч» | `grading.scale`, `grading.credit_hours` |
| Распределение баллов БРС (текущий / рубежный / итоговый) | `grading.assessment_template` |
| Форма силлабуса без ЦУР / со своим разделом | `syllabus.hide_sections`, `syllabus.extra_sections` |
| Политика академической честности, использования ИИ | `syllabus.policies` |
| Тестирование в Moodle, версия | `tests.moodle`, `tests.moodle_version` |
| Требования к ВКР: объём, оригинальность, стиль списка | `research.*` |
| «Рекомендовано УМС университета», формат издания | `manual.*` |
