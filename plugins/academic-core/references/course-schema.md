# Паспорт курса `course.yaml` — схема

Единый источник для силлабуса, РУП, тестов, лекций, УМКД. Лежит в папке курса:
`<рабочая папка>/<курс>/course.yaml`. Полный пример —
`templates/course.example.yaml` («Базы данных», 5 кредитов, 15 недель).

Проверка: `uv run "${CLAUDE_PLUGIN_ROOT}/scripts/validate_course.py" "<путь>/course.yaml"` —
печатает **ошибки** (сборка документов остановится) и **предупреждения** (документ
соберётся, но преподавателю стоит посмотреть). Код возврата 1 — есть ошибки.

Обозначения: **обяз.** — без поля документы не собираются; *реком.* — нужно для
полного силлабуса, без него предупреждение; остальное — необязательно.

## Переводы: суффикс `_ky` / `_en`

Тексты пишутся на языке паспорта (`language`). Для документа на другом языке к
любому текстовому полю можно добавить перевод с суффиксом: `title_ky`, `text_en`,
`srs_task_ky`, `description_en`, `attendance_ky`… Нет перевода — берётся исходный
текст, скрипт предупреждает списком полей. Перечисления (`type`, `cycle`, `level`,
`form`, `language_of_instruction`) всегда пишутся по-русски — скрипт переводит их сам.

## Верхний уровень

| Поле | Тип | | Правило |
|---|---|---|---|
| `schema` | int | | версия схемы, сейчас `1` |
| `language` | `ru` \| `ky` \| `en` | | язык паспорта и документов по умолчанию; нет — из `profile.yaml`, иначе первый из `environment.languages` настроек вуза (`ru`) |
| `languages_extra` | список языков | | параллельные версии документов |
| `course` | объект | обяз. | см. ниже |
| `credits` | int > 0 | обяз. | кредиты по учебному плану; **1 кредит = 30 ч** (вуз задаёт своё в `university/settings.yaml` → `grading.credit_hours`) |
| `hours` | объект | обяз. | часы по видам, **сумма = credits × 30** (× часы кредита вуза) |
| `weeks` | int 1–20 | обяз. | недель в семестре, обычно 15 |
| `teacher` | объект | *реком.* | пустые поля берутся из `profile.yaml` |
| `description` | строка | *реком.* | 3–6 предложений: о чём курс и что студент сделает |
| `goals` | список строк | *реком.* | цели дисциплины |
| `objectives` | список строк | | задачи дисциплины |
| `outcomes` | список | обяз. | результаты обучения (РО), 3–7 штук |
| `competencies` | список | | коды компетенций ООП/ГОС: `"ПК-3"` или `{code, text}` |
| `sdg` | список int 1–17 | *реком.* | номера ЦУР ООН |
| `methods` | список строк | *реком.* | методы обучения (flipped classroom, case study, PBL…) |
| `topics` | список | обяз. | тематический план по неделям |
| `assessment` | список | обяз. | балльно-рейтинговая система, **сумма weight = 100** |
| `grading_scale` | `kr_default` \| список | | шкала перевода баллов в оценку |
| `policies` | объект | *реком.* | политика курса |
| `literature` | объект | *реком.* | литература: `main`, `extra`, `online` |
| `files.out` | строка | | папка для готовых файлов, по умолчанию `out` |

| `program` | строка | | направление подготовки: код и название |
| `level` | `бакалавриат` \| `магистратура` \| `специалитет` \| `аспирантура` | | |
| `year` | int | | курс обучения |
| `semester` | int | | семестр |
| `academic_year` | строка | | `"2026-2027"` |
| `form` | `очная` \| `заочная` \| `дистанционная` | | |
| `language_of_instruction` | строка | | `русский`, `кыргызский`, `английский` |
| `prerequisites` | список строк | | дисциплины, которые нужны до курса |
| `postrequisites` | список строк | | дисциплины, которые опираются на курс |

## `hours`

Виды: `lectures` (лекции), `practicals` (практические / семинары), `labs`
(лабораторные), `srsp` (СРСП — самостоятельная работа под руководством
преподавателя), `srs` (СРС — самостоятельная работа студента). Целые числа ≥ 0.

- **Ошибка**, если `lectures + practicals + labs + srsp + srs ≠ credits × 30`
  (30 — или `grading.credit_hours` из настроек вуза).
- Предупреждение, если аудиторных (Л + П + Лаб) больше 70% объёма.

## `teacher`

`name`, `degree`, `position`, `email`, `office_hours`. Пустое `name/degree/position/email`
берётся из `profile.yaml` рабочей папки.

## `outcomes` — результаты обучения

| Поле | Тип | | Правило |
|---|---|---|---|
| `id` | строка | обяз. | уникальный: `РО1`, `РО2`… |
| `bloom` | уровень | обяз. | `remember` \| `understand` \| `apply` \| `analyze` \| `evaluate` \| `create` |
| `text` | строка | обяз. | **начинается с измеримого глагола Блума** в 3-м лице: «Объясняет…», «Пишет…», «Проектирует…» |
| `competencies` | список строк | | компетенции, к которым относится РО |

- **Ошибка**: неизмеримый глагол — «знает», «понимает», «владеет», «имеет представление»,
  «ознакомлен». Такой РО нельзя проверить.
- Предупреждение: глагол не узнан или обычно относится к другому уровню Блума
  (например, «объясняет» при `bloom: create`).
- В кыргызском тексте глагол стоит в конце: «Реляциялык моделди түшүндүрөт» — скрипт
  смотрит последнее слово.
- Предупреждение, если РО не закрыт ни одной темой.

Глаголы по уровням (ru): запоминание — называет, перечисляет, воспроизводит, определяет;
понимание — объясняет, описывает, интерпретирует, классифицирует, сравнивает;
применение — применяет, использует, решает, вычисляет, пишет, выполняет, строит;
анализ — анализирует, сопоставляет, различает, выявляет, исследует, тестирует;
оценка — оценивает, обосновывает, аргументирует, выбирает, критикует, проверяет;
создание — создаёт, разрабатывает, проектирует, планирует, формулирует, предлагает.

## `topics` — тематический план

| Поле | Тип | | Правило |
|---|---|---|---|
| `week` | int | обяз. | неделя 1…`weeks`, без повторов |
| `title` | строка | обяз. | тема |
| `content` | строка | | краткое содержание (для рабочей программы и лекций) |
| `lab` | строка | | тема лабораторной работы |
| `practical` | строка | | тема практического занятия |
| `control` | строка | | контрольное мероприятие недели: «Рубежный контроль 1» |
| `lectures`, `practicals`, `labs`, `srsp`, `srs` | int ≥ 0 | | часы темы по видам |
| `outcomes` | список id | *реком.* | какие РО закрывает тема; id должны быть в `outcomes` |
| `srs_task` | строка | *реком.* | задание СРС (если у темы есть часы `srs`) |
| `srs_form` | строка | | форма отчёта по СРС |
| `srs_due` | int | | неделя сдачи СРС |

- **Ошибка**, если сумма часов тем по виду ≠ `hours` того же вида — для `lectures`,
  `practicals`, `labs`, `srs`; для `srsp` — только если хоть у одной темы указан `srsp`.
- Предупреждение: недели без темы; тема без РО; часы СРС без задания.

## `assessment` — балльно-рейтинговая система

| Поле | Тип | | Правило |
|---|---|---|---|
| `name` | строка | обяз. | «Лабораторные работы», «Рубежный контроль 1», «Итоговый экзамен» |
| `weight` | число > 0 | обяз. | максимум баллов; **сумма всех = 100** |
| `type` | `current` \| `midterm` \| `final` | | текущий / рубежный / итоговый; нет — `final`, если в названии «экзамен», иначе `current` |
| `week` | int | | неделя проведения |
| `weeks` | список int | | несколько недель — баллы делятся поровну |
| `form` | строка | | форма: тест, письменная работа, защита проекта |

В календарном графике: `week`/`weeks` — баллы в эти недели; `final` без недели —
в колонку «Сессия»; `current` без недели — поровну на все недели семестра.
Предупреждение, если нет итогового контроля.

## `grading_scale`

`kr_default` или поля нет (по умолчанию) — шкала вуза из `university/settings.yaml` →
`grading.scale`; настроек нет — типовая шкала вузов КР (справочник —
`references/university-settings.md`):

| Баллы | Буква | Оценка |
|---|---|---|
| 87–100 | A | отлично |
| 80–86 | B | хорошо |
| 74–79 | C | хорошо |
| 68–73 | D | удовлетворительно |
| 61–67 | E | удовлетворительно |
| 0–60 | F | неудовлетворительно |

Своя шкала вуза — список строк `{min, max, letter, grade}`; `grade` — строка или
`{ru, ky, en}`. **Ошибка**, если диапазоны не покрывают 0–100 без пропусков.

## `policies`

`attendance`, `late_work`, `academic_integrity`, `ai_use` — строки (*реком.*);
`extra` — список дополнительных правил. Пустой пункт берётся из политики вуза
(`university/settings.yaml` → `syllabus.policies`), если она задана.

## `literature`

`main` (основная), `extra` (дополнительная), `online` (интернет-ресурсы) — списки
записей `{text, verified, doi?, url?, source?}`:

- `text` — библиографическая запись по ГОСТ Р 7.0.100-2018 (обяз.);
- `verified: true` — запись найдена в Crossref, OpenAlex, Semantic Scholar,
  КиберЛенинке или в файлах преподавателя;
- без `verified: true` — в документе с пометкой `[НЕ ПРОВЕРЕНО]` и предупреждение;
  с флагом `--final` в документ не попадает.

## Сводка проверок

| Проверка | Уровень |
|---|---|
| нет `course.title`, `credits`, `hours`, `weeks`, `outcomes`, `topics`, `assessment` | ошибка |
| часы по видам ≠ кредиты × 30 | ошибка |
| часы по темам ≠ часы по видам | ошибка |
| веса оценивания ≠ 100 | ошибка |
| РО с неизмеримым глаголом, неверный `bloom`, повтор `id` | ошибка |
| тема ссылается на несуществующий РО, неделя вне 1…weeks или повторяется | ошибка |
| `grading_scale` с дырами, `sdg` вне 1–17 | ошибка |
| нет кода, ФИО, описания, целей, ЦУР, методов, политики, основной литературы | предупреждение |
| глагол Блума не узнан или не того уровня | предупреждение |
| РО без темы, тема без РО, СРС без задания, неделя без темы | предупреждение |
| непроверенная литература | предупреждение |
