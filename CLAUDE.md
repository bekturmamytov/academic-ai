# academicAI — плагины Claude Code для преподавателей вуза

Публичный репо-маркетплейс: `bekturmamytov/academic-ai`. Продукт AI Lab
(ОсОО «Девлайн»), лицензия PolyForm Noncommercial 1.0.0.

**Все решения — в `docs/SPEC.md`. Прочитай его перед любой работой.** Решения
меняет только владелец; правку вносить в SPEC с датой.

## Структура

| Путь | Что |
|---|---|
| `.claude-plugin/marketplace.json` | каталог маркетплейса, четыре плагина |
| `plugins/academic/` | пакет: зависимости + `setup` (проверка окружения) |
| `plugins/academic-core/` | паспорт курса, силабус, РУП, тесты, СРС, лекции, презентации, УМКД, пособия, отчёты |
| `plugins/academic-research/` | реферат … кандидатская, статьи, литература, ГОСТ |
| `plugins/academic-media/` | видео-лекции Remotion, озвучка ElevenLabs |
| `installer/` | промпт-установщик, `install.sh` / `install.ps1` |
| `docs/` | SPEC, нормы КР (`docs/norms/`), планы |

Skill — `plugins/<плагин>/skills/<имя>/SKILL.md` (+ `references/`, `templates/`, `scripts/`).

## Правила, которые нельзя нарушать

- **Нормы КР** — Минобрнауки КР, ГОС ВПО, НАК КР, ГОСТ 7.0.5 / 7.0.100. Языки ru, ky, en.
- **Паспорт курса** (`course.yaml`) и научной работы (`work.yaml`) — единый
  источник; документы собираются из него, а не с нуля.
- **Литература только проверенная** (Crossref, OpenAlex, Semantic Scholar,
  КиберЛенинка, файлы пользователя), иначе `[НЕ ПРОВЕРЕНО]`.
- **Данные и результаты исследований не выдумывать никогда.**
- Студенческие работы — задание, методичка, критерии, рецензия; не готовая работа за студента.
- **Никакого «academicAI» / «AI Lab» внутри документов пользователя.**
- В репо нет данных конкретного вуза, клиентов и ключей. Шаблоны вуза — у
  пользователя локально (`university/`), ключи — `userConfig` / `.env`.
- docx/xlsx/pptx/pdf — через нативные skills Anthropic (`anthropics/skills`);
  их код **не копировать** в репо — лицензия запрещает.
- Каждый skill кончается самопроверкой по чек-листу и показывает ошибки списком.
- Пути и команды — кроссплатформенно (macOS и Windows): без bash-only трюков в
  инструкциях для пользователя, скрипты — Python или Node.
