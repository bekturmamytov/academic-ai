# academicAI — спецификация

Агентская система для академического состава вуза: набор плагинов Claude Code,
которые преподаватель ставит одной командой и использует в Claude Desktop
(вкладка Code) или в VS Code.

Решения приняты владельцем AI Lab 30.10.2026 (интервью-разбор). Меняются только
его решением — правку фиксировать здесь же с датой.

## 1. Кто пользуется

- **Преподаватель** на своём ноутбуке (macOS или Windows). Документы
  (docx, xlsx, pptx) работают почти без установки.
- **Оператор** (методист, IT вуза) ставит тяжёлый конвейер: Typst-вёрстка,
  Remotion-видео, озвучка.
- Поддерживаем обе ОС; у преподавателей скорее Windows.

## 2. Нормы и языки

- Нормы **Кыргызстана**: положения Минобрнауки КР о силабусе, РУП, УМКД;
  ГОС ВПО КР; кредитная система (1 кредит = 30 ч); НАК КР для диссертаций.
- Библиография: ГОСТ Р 7.0.5-2008 / 7.0.100-2018; для зарубежных журналов — APA, IEEE.
- Языки: **ru и ky** основные, **en** для статей и международных программ.
  Документ собирается на одном языке или параллельно на двух (ru+ky).
- Устойчивое развитие: привязка к ЦУР ООН (SDG 1–17) в силабусах и лекциях;
  активные методы — flipped classroom, case study, PBL; результаты обучения
  по таксономии Блума.
- Образцов от вуза пока нет — строим по общим нормам КР и типовым формам,
  под вуз подгоняем, когда появятся (слой `university/`).

## 3. Состав: один маркетплейс, четыре плагина

| Плагин | Что внутри | Зависимости |
|---|---|---|
| `academic` | пакет: только зависимости на три плагина ниже + `setup` | — |
| `academic-core` | паспорт курса, силабус, РУП, тесты, СРС, задания, лекции, презентации, УМКД, учебно-методические пособия, отчёты | нативные skills Anthropic (docx, xlsx, pptx, pdf) |
| `academic-research` | реферат, доклад, курсовая, диплом, магистерская, статья, кандидатская; литература, оформление по ГОСТ | + Typst (опционально) |
| `academic-media` | видео-лекции (Remotion), озвучка (ElevenLabs), субтитры | Node, ffmpeg, Chrome, ключ ElevenLabs |

Установка одной командой:

```
claude plugin install academic --marketplace bekturmamytov/academic-ai
```

Внутри сессии — `/plugin`. Плюс готовый промпт-установщик
(`installer/PROMPT.md`): пользователь вставляет его в Claude Code, Claude ставит
плагины, проверяет окружение и доставляет недостающее с подтверждением.
Если зависимости плагинов поведут себя не так — запасной путь `install.sh` / `install.ps1`.

## 4. Репозиторий и лицензия

- Публичный `github.com/bekturmamytov/academic-ai`, папка `~/Developer/1_PROJECTS/ACADEMIC_AI`.
- Лицензия **PolyForm Noncommercial 1.0.0**: бесплатно для преподавателей и вузов
  (образовательные учреждения прямо разрешены), коммерческая перепродажа — только
  по договору с ОсОО «Девлайн». Доход AI Lab — внедрение, слой вуза, обучение, поддержка.
- В репо **нет ничего от конкретного вуза** и никаких ключей: шаблоны вуза и
  `.env` живут локально у пользователя.

## 5. Порядок работ

Всё сразу, в два слоя:

1. **Ширина** — все skills трёх плагинов работают от начала до конца по нормам КР
   на ru/ky/en; видео — простое (слайды + голос + Remotion), с меткой beta.
2. **Глубина** — по одному документу доводим на реальных образцах:
   силабус → РУП → тесты → лекция/презентация → УМКД → наука → видео.

## 6. Форматы

| Документ | Основной | Дополнительно |
|---|---|---|
| Силабус, УМКД, СРС, задания, отчёты | docx | PDF из docx |
| РУП, график, банк тестов | xlsx | тесты — docx (бланк) и Moodle GIFT / XML |
| Лекция → презентация | pptx | PDF слайдов |
| Учебно-методическое пособие, сборник лекций | Typst → PDF (обложка, оглавление, выходные данные) | docx-исходник |
| Реферат … кандидатская, статья | docx по ГОСТ (поля, Times 14, интервал 1,5) | Typst PDF чистовик |
| Видео-лекция | mp4 1920×1080 | субтитры .srt |

docx/xlsx/pptx/pdf генерируют **нативные skills Anthropic** (`document-skills@anthropic-agent-skills`) из маркетплейса
`anthropics/skills`. Их лицензия не разрешает копировать к нам — ставятся
рядом, наши skills на них опираются: содержание, структура и нормы КР — наши,
сборка файла — их.

**Уточнение 30.10.2026 (реализация):** документы со строгой структурой — силабус,
РУП, тесты (GIFT/XML), презентации, docx по ГОСТ, УМКД — собирают наши скрипты
на открытых библиотеках (python-docx, openpyxl, python-pptx; MIT/BSD), запуск
`uv run`: одинаковый результат на macOS и Windows, автотесты. Нативные skills —
для свободной правки готовых файлов. Код Anthropic не копируется.

Жёсткой зависимостью `document-skills` **не объявлен**: проверено 30.10 —
зависимость из чужого маркетплейса сама не ставится, и плагин тогда не загружается.
Ставит его установщик (`installer/PROMPT.md`, README) и `/academic:setup`.

## 7. Рабочая папка и паспорт курса

```
Мои курсы/                      ← рабочая папка, открывается в Claude Desktop / VS Code
  profile.yaml                  ← ФИО, степень, должность, кафедра, вуз, язык
  university/                   ← логотип, шапка, brand.yaml, положения вуза (необязательно)
  ИС-201 Базы данных/
    course.yaml                 ← паспорт курса — единый источник
    syllabus.docx  rup.xlsx  tests.xlsx  tests.gift
    lectures/  umkd/  out/
  Научная работа/<тема>/
    work.yaml  chapters/  sources/
```

- `course.yaml`: код, название, кредиты, часы (лекции/практики/лабораторные/СРС),
  темы по неделям, результаты обучения (Блум), ЦУР, оценивание, литература.
- Новый курс заполняется вопросами или из старого силабуса (docx/pdf).
- Все документы курса собираются **из паспорта** — поменял часы, пересобрал,
  всё сходится.
- Папку можно держать в OneDrive / Google Drive.

## 8. Источники и академическая честность

- **Литература только проверенная**: Crossref, OpenAlex, Semantic Scholar,
  КиберЛенинка или файлы пользователя. Без DOI / найденной записи —
  `[НЕ ПРОВЕРЕНО]`, в чистовик не попадает.
- **Данные и результаты не выдумываются никогда.** Нет данных — каркас главы
  с пометкой «нужны ваши данные».
- **Режим соавтора**: структура, план, черновик на материалах пользователя,
  редактура, оформление, проверка логики и ссылок.
- **Работы студентов** (реферат, курсовая, диплом): преподаватель получает
  задание, методичку, критерии оценки и рецензию — не готовую работу за студента.

## 9. Видео-лекции

- Источник — готовая лекция (текст + pptx из `academic-core`).
- Remotion 16:9, анимированные слайды, титры, заставка (курс, ФИО).
- Голос на выбор: ElevenLabs по ключу преподавателя (`eleven_v3`, ru/ky/en,
  клонирование своего голоса — их аккаунт и согласие); своя запись, разложенная
  по слайдам; без голоса — только титры.
- Нарезка по темам, 8–15 мин на ролик.
- Аватара нет в первой версии.
- **Проверить**: качество `eleven_v3` на кыргызском; если плохо — для ky по
  умолчанию своя запись или титры.

## 10. Оформление

- Официальные документы — строго по форме, без «дизайна»; логотип и шапка — из `university/`.
- Презентации и пособия — спокойная академическая тема (белый фон, один акцент,
  схемы вместо стен текста); цвет и логотип — из `university/brand.yaml`.
- **Никакого «academicAI» / «AI Lab» внутри документов** — они принадлежат
  преподавателю. Наше имя — только README, установщик, ailab.kg.
- Об ИИ в документе не пишем и не прячем; в научных skills — напоминание о
  правилах раскрытия использования ИИ журнала / НАК, если такие есть.

## 11. Качество

1. **Самопроверка** в каждом skill по чек-листу норм КР перед выдачей
   (разделы, часы = кредиты × 30, глаголы Блума, ключи к тестам, проверенная литература).
2. **Evals** — `claude plugin eval`, 2–3 кейса и грейдер на skill, перед каждым релизом.
3. **GitHub Actions** — `claude plugin validate` на каждый push.
4. Релизы с тегами (`claude plugin tag`), пользователи на стабильной версии.

## 12. Открытые вопросы

- Название вуза-клиента, ОС преподавателей, есть ли Moodle.
- Образцы силабуса, РУП, УМКД, положения вуза.
- Кыргызский в `eleven_v3`: по списку моделей API поддерживается (30.10),
  `eleven_multilingual_v2` — нет. Слушает пилотный преподаватель на своём ключе
  (skill велит сначала озвучить 2–3 слайда).

Решение 01.11.2026: ElevenLabs — только ключ самого преподавателя
(`~/.academic/.env`, `key.py --open` / `--check`). Аккаунт AI Lab в продукт не
подключаем; userConfig из `academic-media` убран — его значение скриптам не видно,
а лишний вопрос при установке путает.
